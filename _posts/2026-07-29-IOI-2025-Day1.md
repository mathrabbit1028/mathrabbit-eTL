# 문제 1 (Souvenirs)

## 만점 풀이

### `solve` 함수

첫 번째 구매에 얼마를 사용해야 할까? 물건을 하나도 구매하지 않으면 실패하기 때문에, $P0-1$만큼의 돈을 사용하여 첫 번째 구매를 진행하는 것이 합리적이다. 그러면 당연히도 $1$번 물건을 구매하게 될 것이다.

이렇게 되면 두 번째 구매가 어려워진다. $1$번 물건을 두 개 이상 사면 실패하기 때문에, 무조건 $1$번 물건 미만의 돈에 대해 `transaction`을 호출해야 한다. 따라서, $1$번 물건의 가격의 하한을 구해야 한다. 산 물건의 목록이 $a_i~(1 \leq i \leq k)$이고 가격 합이 $M$일 때,

$$\sum_{i=1}^k P_{a_i} = M \leq P_1 \cdot k - \sum_{i=1}^k (a_i - 1)$$

가 성립함을 생각하자. 이 부등식의 결과 $P_1$의 하한 $L$을 구할 수 있다. 따라서, 다음 구매는 $L-1$이 될 것이고, 처음과 문제 상황이 똑같으므로 재귀적으로 호출하면 된다. 이제 편의상 $L-1$로 `transaction`을 호출했을 때 제일 처음 사는 물건을 $t$번 물건이라고 하자. 이것은 다음과 동치이다:

$$P_{t-1} > L-1 \geq P_t.$$

### `fill_price` 함수

이 방법의 문제는 여전히 $1$번 물건의 가격을 알 수 없다는 것이다. 결국 $1$번 물건의 가격을 알아내려면 $2$번부터 $N$번까지 물건의 가격을 다 알아내야 한다. 재귀적인 호출의 결과로 $t$번 물건부터 $N$번 물건까지의 가격을 전부 알아낼 것이라 생각하면, 우리는 $2$번부터 $t-1$번까지의 물건의 가격을 알아내면 충분하다.

여전히 $1$번 물건은 더 구매하면 안되므로 $1$번 물건의 하한보다 낮은 가격으로 `transaction`을 호출해야 한다. 따라서 하한을 높이지 않는 이상 다른 방법이 없다. 여기서 알아낸 정보를 쓰자. $t$번부터 $N$번 물건까지의 가격을 알아냈으므로 그 가격들을 대입하자. 그러면 다음 두 가지 경우가 나온다:
- 남은 물건이 하나인 경우: 이 경우 $1$번 물건의 가격이 나온다. 그러면 $1$번 물건이 없어진 상황과 같아진다.
- 남은 물건이 여러 개인 경우: $L$이 평균보다 크다는 점을 생각하면 모든 $P_{a_i} \geq L$일 수는 없다. 즉, 적어도 하나 이상의 물건의 가격은 알아냈을 것이고, 따라서 하한 $L$을 다시 계산하면 바뀐다. 이제 바뀐 $L$에 대해 $L-1$로 `transaction`을 호출하면 $1$번 물건을 다시 살 일은 없다. 구현에서는 $L-1$을 평균의 버림으로 러프하게 추정하였고, 크게 문제되지 않았다.

### 마무리

가장 신경써야 할 부분은 $i$번 물건이 $i$번 이하로 사져야 한다는 사실이다. 이것은 다음 논리에 따라 보장된다:
- $P_i$ 이상 $P_{i-1}$ 미만의 수가 주어진 subproblem 안에서는 $i$번 물건은 $1$번 이하로 산다.
- $i$번 물건은 $1, 2, \ldots, i-1$에 대응되는 subproblem 안에서 각각 최대 한 번 구매될 수 있다.
- 각 subproblem은 많아야 한 번 실행된다; subproblem이 끝나고 나면 $i$번 물건의 가격을 알 수 있게 되기 때문에 호출할 이유가 없다.
- 따라서, $i$번 물건은 $1$번 이하로 사진다.

이것을 증명했으므로, 사진 횟수를 카운팅하고 부족한 물건에 한해서 알아낸 가격 $P_i$로 `transaction`을 호출하면 문제를 마무리할 수 있다.

```cpp
#include "souvenirs.h"
#include <bits/stdc++.h>
using namespace std;

vector<long long> P;
vector<int> cnt;
int r;

void simplify(vector<int>& vec, long long& sum) {
    while (vec.back() >= r) {
        sum -= P[vec.back()];
        vec.pop_back();
        assert(!vec.empty());
    }
}

void decrease_r() {
    while (r > 0 && P[r-1] != -1) r--;
}

void fill_price(vector<int> vec, long long sum) {
    while (true) {
        simplify(vec, sum);
        assert(vec.size() >= 1);

        if (vec.size() == 1) {
            P[vec.front()] = sum;
            decrease_r();
            if (r > vec.front()) {
                pair<vector<int>, long long> res = transaction(P[vec.front()] - 1);
                for (int x : res.first) cnt[x]++;
                fill_price(res.first, P[vec.front()] - 1 - res.second);
            }
            break;
        } else {
            long long tot = sum / vec.size();
            pair<vector<int>, long long> res = transaction(tot);
            for (int x : res.first) cnt[x]++;
            fill_price(res.first, tot - res.second);
        }
    }
}

void solve(long long prev, int N) {
    pair<vector<int>, long long> res = transaction(prev - 1);
    long long sum_max = prev - 1 - res.second;
    vector<int> vec = res.first;
    int i = vec.front();
    for (int x : vec) {
        sum_max += (x - i);
        cnt[x]++;
    }
    if (i == N-1) {
        assert(vec.size() == 1);
        P[N-1] = sum_max;
        r = N-1;
        return;
    }
    long long lower = (sum_max + vec.size() - 1) / (vec.size());
    solve(lower, N);

    fill_price(vec, prev - 1 - res.second);
}

void buy_souvenirs(int N, long long P0) {
    P.resize(N, -1);
    cnt.resize(N, 0);
    P[0] = P0;

    solve(P0, N);

    // for (int i = 0; i < N; i++) cout << P[i] << " ";
    // cout << endl;

    for (int i = 0; i < N; i++) {
        assert(cnt[i] <= i);
        while (cnt[i] < i) {
            transaction(P[i]);
            cnt[i]++;
        }
    }
}
```

# 문제 2 (Triple Peaks)

Part 1만 설명한다.

## Part 1 만점 풀이 (70점)

항상 $i < j < k$ 순을 가정하고, $H[j]$가 무엇에 대응되는지에 따라 나누어 풀 것이다. 참고로, 중복 체크를 위해 $res[j]$에 $(i, k)$를 저장해야 한다.

- case 1: $j - i = H[j]$인 경우
    - $k - i = H[i]$이거나 $k - j = H[i]$이어야 한다. $j$를 고르면 $i$, $k$ 순으로 결정되므로 $\mathcal{O}(N)$에 판단할 수 있다.
- case 2: $k - j = H[j]$인 경우
    - $k - i = H[k]$이거나 $j - i = H[k]$이어야 한다. $j$를 고르면 $k$, $i$ 순으로 결정되므로 $\mathcal{O}(N)$에 판단할 수 있다.
- case 3: $k - i = H[j]$인 경우
    - case 3-1: $j - i = H[i], k - j = H[k]$인 경우이다. 이 경우 $i$를 고르면 $j$, $k$ 순으로 결정되므로, $\mathcal{O}(N)$에 판단할 수 있다.
    - case 3-2: $j - i = H[k], k - j = H[i]$인 경우이다. 아래에서 자세히 설명하겠다.

사실 바로 값이 결정되지 않는 경우는 3-2가 유일하다. 따라서 3-2를 $\mathcal{O}(N^2)$보다 빠르게 해결하는 법을 설명하겠다. 먼저 조건을 보기 좋게 쓰면

$$i - H[i] = j - H[j], \quad i + H[i] = k - H[k], \quad j + H[j] = k + H[k]$$

와 동치이다. 이제 모든 $x$에 대해 $(x - H[x], x + H[x])$을 모은 집합을 전체집합이라고 하자. 참고로 이 집합에 겹치는 점은 없다. $i$를 고정하고 $(j, k)$의 수를 셀 것이다.
- $x$좌표가 $i - H[i]$인 점들의 집합을 $A_i = \{\ldots,a_p + H[a_p],\ldots\}$라고 하자. 이것은 $i - H[i] = a_p - H[a_p]$인 $a_p$들을 의미한다. 즉, 첫 번째 조건에서 $j \in \{\ldots,a_p,\ldots\}$.
- $x$좌표가 $i + H[i]$인 점들의 집합을 $B_i = \{\ldots,b_q + H[b_q],\ldots\}$라고 하자. 이것은 $i + H[i] = b_q + H[b_q]$인 $b_q$들을 의미한다. 즉, 두 번째 조건에서 $k \in \{\ldots,b_q,\ldots\}$.
- 마지막 조건은 $j + H[j] \in B_i$가 된다. 이것은 $A_i$의 각 원소에 대해 $B_i$에 있는 개수를 세서 다 더하면 된다는 것이다.

$A_i$와 $B_i$를 구하는 방법은 간단하다. 고정된 $x$좌표에 대한 $y$좌표의 목록이므로 $x$좌표마다 `std::unordered_set`을 하나씩 만들면 된다.

마지막 조건을 만족하는 $(j, k)$의 수를 세기 위해 버킷화와 비슷한 아이디어를 쓴다:
- 기준 크기 $B$에 대해 $A_i$와 $B_i$의 크기가 둘 다 $B$보다 크다면, 처음 탐색에 대해서만 $\mathcal{O}(B^2)$에 세고, 그 결과를 memoization한다. 이후에는 $\mathcal{O}(1)$에 답을 얻는다.
    - (A_i, B_i) 쌍은 많아야 $\mathcal{O}(N^2/B^2)$개밖에 없으므로, 전체 시간복잡도는 $\mathcal{O}(N^3/B^2)$가 된다.
- 둘 중 하나의 크기가 $B$보다 작다면, 작은 쪽을 기준으로 삼아 $\mathcal{O}(B)$에 세면 된다.
    - 이러한 $i$는 많아야 $\mathcal{O}(N)$개밖에 없으므로, 전체 시간복잡도는 $\mathcal{O}(N \cdot B)$가 된다.
최소가 되는 $B$를 잡으면, $B = N^{2/3}$이 된다. 따라서 전체 시간복잡도는 $\mathcal{O}(N^{5/3})$이다.

참고로, 3-2 경우는 $res[j]$에 넣지 않았기 때문에 $res[j]$ 안에서 3-2에도 해당하는 경우라면 무시하고 최종 답을 구해야 한다. 전체 시간복잡도는 $\mathcal{O}(N^{5/3})$이다.

```cpp
#include "triples.h"

#include <bits/stdc++.h>
using namespace std;

set<pair<int, int>> res[202020];
unordered_map<int, unordered_set<int>> nums;
map<pair<int, int>, long long> memo;

long long count_triples(vector<int> H) {
    int N = H.size();
    for (int i = 0; i < N; i++) {
        res[i].clear();
    }
    nums.clear();
    memo.clear();

    long long ans = 0;
    int i, j, k;
    for (j = 0; j < N; j++) {
        // case 1
        i = j - H[j];
        if (i >= 0) {
            k = i + H[i];
            if (k < N && H[k] == k-j) res[j].insert({i, k});
            k = j + H[i];
            if (k < N && H[k] == k-i) res[j].insert({i, k});
        }
        // case 2
        k = j + H[j];
        if (k < N) {
            i = k - H[k];
            if (i >= 0 && H[i] == j-i) res[j].insert({i, k});
            i = j - H[k];
            if (i >= 0 && H[i] == k-i) res[j].insert({i, k});
        }
    }
    // case 3-1
    for (i = 0; i < N; i++) {
        j = i + H[i];
        if (j >= N) continue;
        k = i + H[j];
        if (k >= N) continue;
        if (H[k] == k-j) res[j].insert({i, k});
    }
    // case 3-2
    const size_t B = static_cast<size_t>(pow(N, 2.0 / 3.0));
    for (int i = 0; i < N; i++) {
        nums[i - H[i]].insert(i + H[i]);
    }
    for (int i = 0; i < N; i++) {
        int a = i - H[i], b = i + H[i];
        if (nums[a].size() > B && nums[b].size() > B) {
            if (memo.find({a, b}) != memo.end()) ans += memo[{a, b}];
            else {
                for (auto &n : nums[a]) {
                    if (nums[b].find(n) != nums[b].end()) {
                        memo[{a, b}]++;
                    }
                }
                ans += memo[{a, b}];
            }
        }
        else {
            if (nums[a].size() > nums[b].size()) {
                swap(a, b);
            }
            for (auto &n : nums[a]) {
                if (nums[b].find(n) != nums[b].end()) {
                    ans++;
                }
            }
        }
    }

    for (j = 0; j < N; j++) {
        for (auto &p : res[j]) {
            i = p.first;
            k = p.second;
            if (j - i == H[k] && k - j == H[i] && k - i == H[j]) ans--;
        }
        ans += res[j].size();
    }
    return ans;
}
```

# 문제 3 (World Map)

## 만점 풀이

DFS 트리를 구했다고 하자. 우리의 목표는 일단 DFS 트리의 간선들로만 행렬을 만들고, DFS 트리를 이루지 않는 간선 연결 $(v, u)$는
```txt
? v ?
v u v
? v ?
```
와 같은 모양을 만들어 u 위치에 넣는 것이다. 앞으로 $u$의 역할을 하는 부분은 `-`로 쓰겠다. 이렇게 하는 이유는, DFS 트리의 연결 간선 $(a, b)$에 대해
```txt
  a   a   a
a - a - a - a
  a b a b a b a
a b - b - b a
  a b   b a
```
와 같은 모양을 만들기 위해서이다. 이 모양을 만들면 DFS 트리의 깊이의 두 배 높이로 행렬을 만들 수 있다. 설계는 다음의 규칙대로 한다:
- DFS 트리의 현재 노드 $v$에 대해, `-`의 개수는 $v$의 서브트리의 크기에서 1을 뺀 값이다. 이것으로 충분한 이유는 남은 back edge를 DFS 트리 기준으로 자식을 안으로 가둔다고 정하면, 추가해야 할 back edge가 많아야 $v$의 서브트리의 크기에서 1을 뺀 값이기 때문이다.
- DFS 트리의 자식들을 왼쪽에서 오른쪽으로 붙인다. 이때, 둘 이상의 자식이 붙는 것이 허용되지 않을 수 있으므로, 사이에 $v$를 넣어야 한다.
구현상 폭은 계속 일정한데, 그 이유는 자식이 하나 늘어날 때마다 요구하는 `-`의 개수가 하나씩 줄지만, 사이에 넣어야 하는 $v$의 개수가 하나씩 늘어나기 때문이다. 따라서, 폭은 항상 $2 \cdot sz[v] - 1$이 된다.

다음 예시 세 개를 참고하면 규칙을 익히는데 도움이 될 것이다:
```
// example 1
1 2     _ 1 _ 1 _ 1
2 4       2 1 2 1 2
4 3     2 _ 2 _ 2                   2 _ 2 _ 2
          2 4 2 4 2
        2 4 _ 4 2                     4 _ 4
          2 4 3 4 2

// example 2
1 2     _ 1 _ 1 _ 1 _ 1 _ 1
1 3       2 1 3 1 3 1 3 1 4
1 4     2 1 3 _ 3 _ 3 1 4           2 / 3 _ 3 _ 3 / 4
3 5       2 1 3 5 3 5 3 1 4
5 6     2 1 3 5 _ 5 3 1 4                 5 _ 5
          2 1 3 5 6 5 3 1 4

// example 3
1 2     _ 1 _ 1 _ 1 _ 1 _ 1
1 3       2 1 2 1 3 1 3 1 4 
1 4     2 _ 2 1 3 _ 3 1 4           2 _ 2 / 3 _ 3 / 4
2 5       2 5 2 1 3 6 3 1 4
3 6
```
왼쪽은 DFS 트리를 이루는 간선의 목록이고, 가운데는 채워지는 행렬, 오른쪽은 DFS 트리의 자식들에 대응되는 구간을 나눠서 나타낸 것이다.

```cpp
#include "worldmap.h"
#include <bits/stdc++.h>
using namespace std;

vector<int> adj[44];
vector<int> child[44];
int ch[44], sz[44];

void DFS(int v) {
    ch[v] = 1;
    sz[v] = 1;
    for (int u : adj[v]) {
        if (ch[u]) continue;
        DFS(u);
        child[v].push_back(u);
        sz[v] += sz[u];
    }
}

void solve(vector<vector<int>>& ans, int v, int i, int l, int r) {
    ch[v] = 1;

    if (i >= ans.size()) return;
    
    for (int j = l; j < r; j++) ans[i][j] = v;
    int p = l;
    for (int u : adj[v]) {
        if (ch[u]) continue;
        ans[i][p] = u;
        p += 2;
    }
    
    // r - l = 2 * (sz[v] - 1)
    for (int j = l+1; j < r+1; j++) ans[i+1][j] = v;
    p = l + 1;
    for (int u : child[v]) {
        int new_l = p;
        for (int y = i+2; y < ans.size(); y++) {
            if (y % 2 == 0) ans[y][p-1] = u;
            else ans[y][p] = u;
        }
        for (int k = 0; k < sz[u]; k++) {
            ans[i+1][p] = u;
            p += 2;
        }
        solve(ans, u, i+2, new_l, p-2);
        for (int y = i+2; y < ans.size(); y++) {
            if (y % 2 == 0) ans[y][p-2] = v;
            else ans[y][p-1] = v;
        }
    }
    for (int y = i+2; y < ans.size(); y++) {
        if (y % 2 == 0) ans[y][p-2] = v;
        else ans[y][p-1] = v;
    }
}

vector<vector<int>> create_map(int N, int M, vector<int> A, vector<int> B) {

    if (M == 0) {
        vector<vector<int>> ans(1, vector<int>(1, 1));
        return ans;
    }

    for (int i = 1; i <= N; i++) adj[i].clear();
    for (int i = 1; i <= N; i++) child[i].clear();
    for (int i = 1; i <= N; i++) ch[i] = 0;
    for (int i = 1; i <= N; i++) sz[i] = 0;

    for (int i = 0; i < M; i++) {
        adj[A[i]].push_back(B[i]);
        adj[B[i]].push_back(A[i]);
    }
    int root = 1;
    while (adj[root].empty()) root++;
    DFS(root);

    vector<vector<int>> ans(2 * N - 1, vector<int>(2 * N - 1, 0));

    for (int i = 1; i <= N; i++) ch[i] = 0;
    solve(ans, root, 0, 0, 2 * N - 2);
    for (int i = 0; i < 2 * N - 1; i++) {
        for (int j = 0; j < 2 * N - 1; j++) {
            if (ans[i][j] == 0) ans[i][j] = root;
        }
    }

    return ans;
}
```

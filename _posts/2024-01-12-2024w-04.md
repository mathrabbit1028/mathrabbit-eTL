## 1. 최소, 최대 (0:31:18)

어떤 두 수를 비교했을 때 큰 값은 최솟값이 될 수 없고, 작은 값은 최댓값이 될 수 앖다. 즉,인접한 두 개를 비교하는 방식으로 $\lceil \frac{N}{2} \rceil$번의 비교를 통해 최댓값이 될 수 있는 수들과 최솟값이 될 수 있는 수들로 $N$개의 수를 분할할 수 있다. 이때 남는 한 개의 수는 그 직전 수와 비교해 처리하면 된다.

그러면 집합의 크기가 $|S|$일 때 이 집합에서 최댓값 또는 최솟값을 $|S|-1$의 시간에 찾을 수 있으므로 $N + \lceil \frac{N}{2} \rceil - 2$번의 비교로 최댓값과 최솟값을 구할 수 있다.

```cpp
#include "minmax.h"
#include <bits/stdc++.h>
using namespace std;
 
int find_minmax(int N) {
    if (N == 1) return 38;
 
    vector<int> arr;
    for (int i = 0; i < N; i++) arr.push_back(i+1);
 
    vector<int> large, small;
    for (int i = 0; i < arr.size(); i++) {
        if (i % 2 == 0) large.push_back(arr[i]);
        else small.push_back(arr[i]);
    }
    assert(large.size() >= small.size());
    for (int i = 0; i < small.size(); i++) {
        if (large[i] == small[i]) continue;
        if (get_larger_index(large[i], small[i]) == small[i]) swap(large[i], small[i]);
    }
    if (large.size() != small.size()) {
        if (get_larger_index(large.back(), small.back()) == small.back()) {
            small.push_back(large.back());
            large.pop_back();
        }
    }   
 
    int a = small.front();
    for (int i = 1; i < small.size(); i++) {
        a = a + small[i] - get_larger_index(a, small[i]);
    }
    int b = large.front();
    for (int i = 1; i < large.size(); i++) {
        b = get_larger_index(b, large[i]);
    }
    return 37*a + b;
}
```

## 2. 콩 (0:51:03)

두 번째 최댓값을 찾는 문제인데, 토너먼트 형식으로 최댓값을 구하게 되면 직접 비교와 동일하게 $N-1$번의 비교로 최댓값을 찾을 수 있음과 동시에 두 번째 최댓값의 후보가 가장 큰 수한테 토너먼트에서 패배했던 $\lceil \log_2 N \rceil$개의 수 뿐이므로 $N + \lceil \log_2 N \rceil - 2$번의 비교로 문제를 해결할 수 있다.

```cpp
#include <bits/stdc++.h>
#include "kong.h"
using namespace std;
typedef pair<int, int> pii;
 
map<pii, int> m;
 
int solve(int st, int ed) {
    if (st == ed) { m.insert({(pii){st, ed}, st}); return st; }
    int mid = (st + ed) / 2;
    int lt = solve(st, mid);
    int rt = solve(mid+1, ed);
    if (compare(lt, rt) > 0) { m.insert({(pii){st, ed}, lt}); return lt; }
    else { m.insert({(pii){st, ed}, rt}); return rt; }
}
 
void upd(int* ans, int can) {
    if (*ans == 0) *ans = can;
    else if (compare(*ans, can) < 0) *ans = can;
}
 
int kong(int n){
    solve(1, n);
 
    int ans = 0;
 
    int st = 1, ed = n;
    while (st < ed) {
        int mid = (st + ed) / 2;
        if (m[{st, ed}] == m[{st, mid}]) {
            upd(&ans, m[{mid+1, ed}]);
            ed = mid;
        }
        else if (m[{st, ed}] == m[{mid+1, ed}]) {
            upd(&ans, m[{st, mid}]);
            st = mid+1;
        }
    }
    
    return ans;
}
```

## 3. 두 정렬 리스트의 중간 값 (1:39:21)

$A$와 $B$의 두 배열에서 에서 $N$이 존재할 수 있는 구간을 $[s_1, e_1]$, $[s_2, e_2]$라고 하자. 그리고 두 구간의 길이가 같으며 남은 구간의 중앙값도 $N$이라고 가정하자. 그러면 다음 두 가지 경우가 가능하다.

- 구간의 길이가 홀수인 경우
    - 각각의 중앙값 $m_1$과 $m_2$ 중 일반성을 잃지 않고 $m_2$가 크다고 하자. 그러면 $m_2$보다 큰 수는 $[s_1, m_1]$과 $[s_2, m_2]$가 모두 그 수보다 작으므로 중앙값이 될 수 없다. 같은 방법으로 $m_1$보다 작은 수는 중앙값이 될 수 없다.
    - 따라서 $s_1 \gets m_1$, $e_2 \gets m_2$로 구간을 갱신하자. 그러면 $N$보다 큰 수와 작은 수가 같은 개수만큼 제거되었으므로 여전히 남은 구간의 중앙값은 $N$이고, 남은 두 구간의 길이도 같다.
- 구간의 길이가 짝수인 경우
    - 각각의 중앙값 중 작은 값 $m_1$과 $m_2$ 중 일반성을 잃지 않고 $m_2$가 크다고 하자. 그러면 $m_2$보다 큰 수는 $[s_1, m_1]$과 $[s_2, m_2]$가 모두 그 수보다 작으므로 중앙값이 될 수 없다. 같은 방법으로 $m_1$ 이하인 수는 중앙값이 될 수 없다.
    - 따라서 $s_1 \gets m_1+1$, $e_2 \gets m_2$로 구간을 갱신하자. 그러면 $N$보다 큰 수와 작은 수가 같은 개수만큼 제거되므로 여전히 남은 구간의 중앙값은 $N$이고, 남은 두 구간의 길이도 같다.

이렇게 $s_1 = e_1$, $s_2 = e_2$가 될 때까지 하면 남은 수는 $N$과 $N+1$이므로 더 작은 수의 인덱스를 반환하면 된다. 필요한 비교 쿼리의 횟수는 $\lceil \log_2 N \rceil + 1$이다.

```cpp
#include <bits/stdc++.h>
#include "twolist.h"
using namespace std;
 
int twolist(int n){
	int s1 = 1, e1 = n, s2 = 1, e2 = n;
	while (s1 + 1 < e1) {
		int m1 = (s1+e1)/2;
		int m2 = (s2+e2)/2;
		if ((e1 - s1) % 2 == 0) {
			if (compare(m1, m2) > 0) { e1 = m1; s2 = m2; }
			else { s1 = m1; e2 = m2; }
		}
		else {
			if (compare(m1, m2) > 0) { e1 = m1; s2 = m2+1; }
			else { s1 = m1+1; e2 = m2; }
		}
	}
 
	if (compare(s1, s2) > 0) s2++;
	else s1++;
	if (compare(s1, s2) > 0) return s2+n;
	else return s1;
}
```

## 6. 별 연산자 (3:03:14)

전체 그룹을 $k$개씩 나누어 각 그룹에 대해 앞에서부터와 뒤에서부터 누적한 결과를 구하자. 그러면 구간의 길이가 $k$이므로 모든 구간은 한 그룹의 오른쪽 부분과 다른 그룹의 왼쪽 부분의 결합이 된다. 즉, 각 쿼리를 한 번의 연산으로 처리할 수 있고, 전처리는 $2N$번 미만의 연산으로 처리할 수 있다.

```cpp
#include <bits/stdc++.h>
using namespace std;
#include "star.h"
 
int lt[1010], rt[1010];
int k;
 
void init(int N, vector<int> A, int K) {
	k = K;
 
	if (K == 0) {
		for (int i = 0; i < N; i++) lt[i] = A[i];
		return;
	}
 
	for (int i = 0; i < N; i += K) {
		int st = i, ed = min(i+K, N)-1;
		lt[st] = A[st];
		for (int j = st + 1; j <= ed; j++) {
			lt[j] = star(lt[j-1], A[j]);
		}
		rt[ed] = A[ed];
		for (int j = ed - 1; j >= st; j--) {
			rt[j] = star(A[j], rt[j+1]);
		}
	}
}
 
int query(int L, int R) {
	if (k == 0) return lt[L];
	return star(rt[L], lt[R]);
}
```

## 7. 달 연산자 (3:29:36)

6번의 풀이를 응용해 보자. 만약 어떤 구간의 중앙값을 포함한다면 6번과 같이 중앙값부터 왼쪽으로 가는 누적 연산 결과와 오른쪽으로 가는 누적 연산 결과를 더해 한 번의 연산으로 쿼리를 해결할 수 있을 것이다.

이제 어떤 구간의 중앙값을 포함하지 않는 경우를 생각해보자. 그러면 왼쪽 부분 구간 또는 오른쪽 부분 구간에 속할 것이므로 부분 구간에서 위에서 했던 작업을 똑같이 하면 된다. 즉, 분할정복 또는 세그먼트 트리, 희소 배열과 유사한 아이디어로 문제를 해결할 수 있다.

구체적으로 보면 구간 분할은 구간의 길이가 4가 될 때까지만 하면 된다. 왜냐면 구간의 길이가 2이면 두 개의 직접 연산으로 해결할 수 있기 때문이다. 즉, $N(\lceil \log_2 N \rceil-2)$번 이내의 연산으로 전처리할 수 있다.

```cpp
#include "moon.h"
#include <bits/stdc++.h>
using namespace std;
 
int val[9][1010];
int n;
vector<int> arr;
 
void solve(int L, int st, int ed) {
	if (st + 1 >= ed) return;
	int mid = (st + ed) / 2;
	val[L][mid] = arr[mid];
	val[L][mid+1] = arr[mid+1];
	for (int i = mid - 1; i >= st; i--) val[L][i] = moon(arr[i], val[L][i+1]);
	for (int i = mid + 2; i <= ed; i++) val[L][i] = moon(val[L][i-1], arr[i]);
	solve(L+1, st, mid);
	solve(L+1, mid+1, ed);
}
 
void init(int N, vector<int> A) {
	arr = A;
	n = N;
	solve(0, 0, N-1);
}
 
int get(int L, int st, int ed, int lt, int rt) {
	if (st + 1 >= ed) {
		if (lt < rt) return moon(arr[lt], arr[rt]);
		else return arr[lt];
	}
	int mid = (st + ed) / 2;
	if (lt <= mid && mid + 1 <= rt) return moon(val[L][lt], val[L][rt]);
	if (rt <= mid) return get(L+1, st, mid, lt, rt);
	if (lt >= mid+1) return get(L+1, mid+1, ed, lt, rt);
}
 
int query(int L, int R) {
	return get(0, 0, n-1, L, R);
}
```

## 5. 100000원소설

앞에서부터 보면서 순차적으로 진행하다가 정확히 절반이 되면 그룹을 나누자. 이 과정은 단순히 각 그룹의 제일 첫 번째 값과 비교하는 것만으로 충분하다. 왜냐하면 첫 번쨰 값과 두 번째 값이 다르면 그 순간 그룹이 끊기고 다시 새롭게 시작하기 때문이다. 그렇게 전체를 몇 개의 그룹으로 나누었을 때 두 가지 경우가 가능하다.

- 마지막 $N$번까지 그룹에 포함되었을 경우: 가장 많이 있는 원소가 정확히 절반 존재한다는 뜻이므로 답이 없다.
- 마지막 $N$번이 그룹에 포함되지 않은 경우: 그룹에 포함되지 않은 원소들 중 가장 과반인 것은 그룹으로 묶이지 않은 가장 앞쪽에 있는 원소이다. 이제 이 원소와 각 그룹에서 첫 번째 원소였던 것들과 비교하여 같으면 그 그룹의 길이를 2로 나눈 값을 개수에 더하고, 각 그룹에서 첫 번째 원소와 달랐던 것들을 비교하여 같으면 1을 개수에 더하자. 이렇게 얻은 개수가 과반보다 크면 그 원소가 과반보다 많은 원소이다.

이러한 방법에서 비교 횟수를 구해보자. 그룹의 개수가 $G$개라면, 그룹화 과정에서 비교 횟수는 $N-G-2$이고, 그룹을 구하고 과반을 찾는 마지막 과정에서 비교 횟수는 최대 $\lfloor \frac{N}{2} \rfloor + G$번이다. 따라서 $\lfloor \frac{3N}{2} \rfloor$번 이내에 쿼리 호출로 문제를 해결할 수 있다.

```cpp
#include "element.h"
#include <bits/stdc++.h>
using namespace std;
typedef pair<int, int> pii;
 
int element(int n) {
    vector<int> vec, tar;
    int now = 1, cnt = 1, tot = 1;
    for (int i = 1; i <= n; i++) {
        if (now == i) continue;
        tot += 1;
        if (debate(now, i)) cnt += 1;
        else tar.push_back(i);
        if (cnt*2 == tot) {
            vec.push_back(now);
            now = i+1;
            cnt = 1;
            tot = 1;
        }
    }
 
    vec.push_back(now);
 
    //cout << vec.back() << "\n";
 
    if (vec.back() == n+1) return -1;
    
    int res = cnt;
    for (int i = 0; i < vec.size()-1; i++) {
        if (debate(vec.back(), vec[i])) res += (vec[i+1] - vec[i])/2;
    }
    for (int i = 0; i < tar.size(); i++) {
        if (debate(vec.back(), tar[i])) res += 1;
    }
 
    if (res*2 > n) return vec.back();
    else return -1;
}
```

## 8. 실수

https://www.acmicpc.net/problem/26001

우리는 순서대로 따라가며 현재 최댓값보다 더 값이 클 때만 이분탐색으로 $O(\log N)$에 최댓값을 갱신하는 아이디어를 떠올릴 수 있다. 하지만 만약 $a_i=i$와 같은 단조증가하는 수열이라면 최악의 경우 $O(N \log N)$개의 쿼리를 요구할 것이다.

그레이더가 적응적이지 않음을 상기하자. 순서를 셔플하면 최댓값을 갱신하는 횟수가 $O(\log N)$번임을 보일 수 있다. 즉, $N + O(\log^2N)$개의 쿼리로 문제를 해결할 수 있는 것이다.

최대 쿼리 개수가 1,500 개이므로 여유롭게 통과할 수 있다.

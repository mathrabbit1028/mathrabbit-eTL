## 문제 K

반지름이 100 이상이기 때문에 199 간격으로 전체를 커버하는 세로선을 그리면 무조건 걸린다. 한 번 걸리고 나면 좌우로 50만큼 이동된 세로선을 그리면 적어도 하나에는 걸린다. 모든 $y$좌표를 커버하는 직선을 그렸기 때문에, 입력받은 값의 절반이 $y_0$이면 $(x-x_0)^2 + y^2 = r^2$이 성립한다. 즉,걸린 우리는 두 개의 세로선으로 원의 $x$좌표와 반지름을 알 수 있다. 비슷하게, 가로선을 그리면 원의 $y$좌표와 반지름을 알 수 있다.

필요한 쿼리의 개수는 $2 \cdot (10^5 / 199 + 2) \leq 1010$이다.

## 문제 F

가로줄을 나타내는 배열에 $0, 1, 0, 1, \ldots$를 적고, 세로줄을 나타내는 배열에 $0, 1, 0, 1, \ldots$를 적는다. 그러면 

- 각 칸은 가로줄을 나타내는 배열에서 해당하는 값과 세로줄을 나타내는 배열에서 해당하는 값의 합을 2로 나눈 나머지에 따라 색이 결정된다.
- 줄을 뒤집는 것은 숫자를 $0$에서 $1$로, 또는 $1$에서 $0$으로 바꾸는 것과 같다.
- 같은 색으로 칠해진 영역의 수는 각 배열에서 인접한 같은 수끼리 묶었을 때 나오는 그룹의 개수를 곱한 값이다.

뒤집는 쿼리가 들어왔을 때 좌우 칸들만 살피면, 그룹의 개수를 관리할 수 있다. 따라서 시간복잡도는 $\mathcal{O}(n+q)$이다.

## 문제 D

$dp[l][r]$에 $[l, r]$ 구간을 최대한 압축한 문자열의 길이를 저장하자. 그러면 가능한 경우는 다음 두 가지 중 하나다:

- 어떤 인덱스 $i$를 기준으로 $[l, i]$와 $[i+1, r]$로 나누어 압축하는 경우
- $[l, r]$ 구간이 반복되는 패턴으로 이루어져 있다면, 반복되는 패턴의 길이를 $k$라고 했을 때, $[l, r]$ 구간을 $k$개로 나누어 압축하는 경우

수식으로 쓰자면:

$$dp[l][r] = \min(dp[l][i] + dp[i+1][r]) \text{ for } l \leq i < r$$
$$dp[l][r] = \min(dp[l][l+k-1] + 3) \text{ for } k \text{ that divides } (r-l+1)$$

시간복잡도는 $\mathcal{O}(n^3)$이다.

## 문제 G

$dp[N][i]$를 $N$개의 카드 중 $i$번째 카드가 마지막까지 살아남을 확률이라고 하자. 그러면, 1부터 6까지 중 주사위가 무엇이 나오느냐에 따라서 $\mathcal{O}(1)$에 $dp[N][i]$를 계산할 수 있다.

여기서 중요한 것은, $N$에 대해서 대략 $5N/6$ 근처의 두 개의 수만 첫 번째 인덱스로 참조한다는 것이다. 이로부터 첫 번째 인덱스로 요구되는 값이 적을 것으로 추측할 수 있고, 실제로 주어진 문제 범위에서 300개 정도로 작다. 곧, 위 dp 풀이는 $300N$ 풀이가 되어 시간 안에 해결할 수 있다.

## 문제 E

앞에서부터 채운다고 생각하면 앞에 등장한 집합만 중요하다. 즉, bitmask dp를 하기에 너무 좋은 조건이다. 그러면, 집합 $S$에 대해 $dp[S]$에 없는 원소 $k$를 오른쪽에 추가할 수 있을 필요충분조건만 구하면, 가능한 경우에 한해 $dp[S \cup \{k\}] \rightarrow dp[S]$를 갱신하면 된다. 필요충분조건은:

- $a, k, c$ 쌍에 대해, $S$에 $a, c$가 모두 포함되어 있다면, $k$를 추가할 수 없다. 즉, $a \in S$이고 $c \in S$이면 $k \notin S$이다.
- $a, k, c$ 쌍에 대해, $S$에 $a, c$가 모두 포함되어 있지 않다면, $k$를 추가할 수 없다. 즉, $a \notin S$이고 $c \notin S$이면 $k \notin S$이다.

따라서 고정된 $k$에 대해 XOR 조건이 있는 것과 같으므로, $a$와 $c$를 연결한 그래프로 보면, $S$에 있는 대로 색을 칠하면 간선으로 연결된 정점은 서로 다른 색을 가져야 한다. 따라서, 미리 그래프의 각 컴포넌트마다 이분그래프로 색칠을 해두고, $S$가 들어올 때마다 색칠이 유효한지 확인하면 된다. 이분그래프가 아니면, $S$에 상관없이 불가능하다. 

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m;
vector<int> restrictions[30][30];

struct Component {
    int vertices;
    int color;
};

vector<Component> components[24];
bool consistent[24];
int dp[1<<24];

bool possible(int b, int mask) {
    if (!consistent[b]) return false;

    for (const Component &component : components[b]) {
        int selected = mask & component.vertices;
        if (selected != component.color &&
            selected != (component.vertices ^ component.color)) {
            return false;
        }
    }
    return true;
}

void solve() {
    dp[0] = 1;
    for (int mask = 1; mask < (1 << n); mask++) {
        int bits = mask;
        while (bits) {
            int bit = bits & -bits;
            int i = __builtin_ctz(bit);
            if (possible(i, mask ^ bit)) {
                dp[mask] += dp[mask ^ bit];
                if (dp[mask] >= 998'244'353) dp[mask] -= 998'244'353;
            }
            bits ^= bit;
        }
    }
}

int main() {
    cin >> n >> m;
    for (int i = 1; i <= m; i++) {
        int a, b, c;
        cin >> a >> b >> c;
        a--; b--; c--;
        restrictions[b][a].push_back(c);
        restrictions[b][c].push_back(a);
    }

    for (int b = 0; b < n; b++) {
        consistent[b] = true;
        vector<int> color(n, -1);
        for (int start = 0; start < n; start++) {
            if (color[start] != -1 || restrictions[b][start].empty()) continue;

            int vertices = 0, colorMask = 0;
            queue<int> q;
            color[start] = 0;
            q.push(start);
            while (!q.empty()) {
                int u = q.front();
                q.pop();
                vertices |= 1 << u;
                if (color[u]) colorMask |= 1 << u;

                for (int v : restrictions[b][u]) {
                    if (color[v] == -1) {
                        color[v] = color[u] ^ 1;
                        q.push(v);
                    } else if (color[v] == color[u]) {
                        consistent[b] = false;
                    }
                }
            }
            components[b].push_back({vertices, colorMask});
        }
    }

    solve();
    
    cout << dp[(1<<n)-1] << endl;
}
```

## 문제 J

문제의 제약조건은 정점들을 중복을 허락해 $n$번 고르되 각 정점 $v$의 서브트리에서 골라진 횟수가 서브트리의 크기 이하여야 한다는 것이다. 그리고, 정점을 $a$번 고른 상태에서 한 번 더 고르면 $f_v \cdot (2a+1)$의 비용이 필요하다.

따라서, 색칠 횟수 제한을 어기지 않은 정점들 중에서 $f_v \cdot (2a+1)$의 비용이 최소인 것을 선택하는 그리디 알고리즘을 고안할 수 있다:

- 제약조건은 각 정점의 subtree에서 선택된 개수에만 의존하므로, 두 선택의 순서 자체는 제약조건을 바꾸지 않고, 
- 특정 정점이 다른 정점들보다 늦게 선택되는 것이 cost를 바꾸지 않는다. 
- 이에 따라, 어떤 최적해가 존재하더라도 그 첫 번째 선택을 그리디의 선택으로 바꿀 수 있다.

우선순위 큐로 비용들을 관리하자. 색칠 횟수 제한을 어겼는지 여부는 HLD를 이용해 $v$에서 루트로 가는 경로 상에서 모든 정점에 여유가 있는지 확인하면 된다:

- 처음에 서브트리 사이즈로 여유값을 초기화하고,
- cost가 가장 작은게 $v$라면, $v$에서 루트로 가는 경로 상의 모든 정점에 여유가 있는지 확인하고, 여유가 있다면 선택하고, 여유가 없다면 선택하지 않는다.
- 여유가 있어서 선택된 경우, $v$에서 루트로 가는 경로 상의 모든 정점에 여유값을 1씩 감소시키고, 다음 cost를 계산하여 우선순위 큐에 넣는다.

시간복잡도는 $\mathcal{O}(n \log n)$이다.

## 문제 H

Exchange argument를 생각하면, $(s_1, v_1)$이 $(s_2, v_2)$보다 우선될 필요충분조건은:

$$p \cdot v_1 + (p + s_1) \cdot v_2 \geq p \cdot v_2 + (p + s_2) \cdot v_1 \quad \iff \quad s_1 v_2 \geq s_2 v_1$$

이 조건은 partial order를 정의한다. 따라서, exchange argument가 성립한다.

그러면 우리가 찾아야 할 것은, $S = [n]$의 partition $S_1, S_2$에 대해,

$$\max_{S_1, S_2} \left[ p_0 \sum_{i \in S_1} v_{1, i} + \sum_{\substack{i, j \in S_1 \\ (s_{1, i}, v_{1, i}) < (s_{1, j}, v_{1, j})}} s_{1, i} v_{1, j} + p_0 \sum_{i \in S_2} v_{2, i} + \sum_{\substack{i, j \in S_2 \\ (s_{2, i}, v_{2, i}) < (s_{2, j}, v_{2, j})}} s_{2, i} v_{2, j}\right]$$

여기서 $(s_i, v_i) < (s_j, v_j)$는 exchange argument에 의해 $(s_i, v_i)$를 먼저 사용해야 함을 의미한다.

이제 min-cut으로 문제를 해결하자. min-cut의 energy function은, $x_i \in \{0, 1\}$일 때

$$E = \sum_{i} D^0_i \cdot [x_i = 0] + \sum_{i} D^1_i \cdot [x_i = 1] + \sum_{i, j} w_{i, j} \cdot [x_i \neq x_j] = \sum_i D^0_i (1 - x_i) + \sum_i D^1_i x_i + \sum_{i, j} w_{i, j} |x_i - x_j|$$

의 general한 form을 갖는다:

- $D^0_i$는 $x_i = 0$일 때 코스트이므로, source와 연결된 간선을 $x_i = 1$로 라벨링하면 source에서 $i$로 가는 간선의 capacity다.
- $D^1_i$는 $x_i = 1$일 때 코스트이므로, sink와 연결된 간선을 $x_i = 0$로 라벨링하면 $i$에서 sink로 가는 간선의 capacity다.
- $w_{i, j}$는 $x_i \neq x_j$일 때 코스트이므로, $i$와 $j$를 연결하는 **양방향** 간선의 capacity다.

한편, $x_i = [i \in S_1]$이라 하면 $x_i x_j = \frac{1}{2} (x_i + x_j - |x_i - x_j|)$이므로, 우리의 목표를 min-cut의 energy function으로 나타낼 수 있다.

1. 일차항

$$\begin{align*} \max_{S_1, S_2} \left[ p_0 \sum_{i \in S_1} v_{1, i} + p_0 \sum_{i \in S_2} v_{2, i} \right] &= \max_{x_i} \left[ \sum_i p_0 v_{1, i} x_i + \sum_i p_0 v_{2, i} (1 - x_i) \right] \\ &= p_0 \sum_i v_{1, i} + p_0 \sum_i v_{2, i} - \min_{x_i} \left[ \sum_i p_0 v_{1, i} (1 - x_i) + \sum_i p_0 v_{2, i} x_i\right] \end{align*}$$

2. 이차항

$$\begin{align*} \max_{S_1, S_2} \left[ \sum_{\substack{i, j \in S_1 \\ (s_{1, i}, v_{1, i}) < (s_{1, j}, v_{1, j})}} s_{1, i} v_{1, j} \right] &= \max_{x_i} \left[ \sum_{i, j} s_{1, i} v_{1, j} x_i x_j \right] \\ &= \max_{x_i} \left[ \sum_{i, j} s_{1, i} v_{1, j} \frac{1}{2} (x_i + x_j - |x_i - x_j|) \right] \\ &= \max_{x_i} \left[ \sum_{i, j} s_{1, i} v_{1, j} \frac{1}{2} (x_i + x_j) - \sum_{i, j} s_{1, i} v_{1, j} \frac{1}{2}|x_i - x_j| \right] \\ &= \sum_{i, j} s_{1, i} v_{1, j} - \min_{x_i} \left[ \sum_{i, j} \frac{1}{2} s_{1, i} v_{1, j} |x_i - x_j| + \sum_i \frac{1}{2} s_{1, i} v_{1, j} (1 - x_i) + \sum_i \frac{1}{2} s_{1, i} v_{1, j} (1 - x_j) \right] \end{align*}$$

$$\begin{align*} \max_{S_1, S_2} \left[ \sum_{\substack{i, j \in S_2 \\ (s_{2, i}, v_{2, i}) < (s_{2, j}, v_{2, j})}} s_{2, i} v_{2, j} \right] &= \max_{x_i} \left[ \sum_{i, j} s_{2, i} v_{2, j} (1 - x_i) (1 - x_j) \right] \\ &= \max_{x_i} \left[ \sum_{i, j} s_{2, i} v_{2, j} \frac{1}{2} (2 - x_i - x_j - |x_i - x_j|) \right] \\ &= \sum_{i, j} s_{2, i} v_{2, j} - \min_{x_i} \left[ \sum_{i, j} \frac{1}{2} s_{2, i} v_{2, j} |x_i - x_j| + \sum_i \frac{1}{2} s_{2, i} v_{2, j} x_i + \sum_i \frac{1}{2} s_{2, i} v_{2, j} x_j \right] \end{align*}$$

정점 $O(n)$개, 간선 $O(n^2)$개이므로, max-flow min-cut 알고리즘으로 해결할 수 있다.

```cpp
#include <bits/stdc++.h>

using namespace std;

class MaxFlow {
    struct Edge {
        int to, rev;
        long long cap;
    };

    struct OriginalEdge {
        int from, index;
        long long capacity;
    };

    int n;
    vector<vector<Edge>> graph;
    vector<OriginalEdge> original_edges;
    vector<int> level, work;

    bool bfs(int source, int sink) {
        fill(level.begin(), level.end(), -1);
        queue<int> q;
        level[source] = 0;
        q.push(source);

        while (!q.empty()) {
            int v = q.front();
            q.pop();
            for (const Edge &edge : graph[v]) {
                if (edge.cap > 0 && level[edge.to] == -1) {
                    level[edge.to] = level[v] + 1;
                    q.push(edge.to);
                }
            }
        }
        return level[sink] != -1;
    }

    long long dfs(int v, int sink, long long flow) {
        if (v == sink) return flow;

        for (int &i = work[v]; i < static_cast<int>(graph[v].size()); i++) {
            Edge &edge = graph[v][i];
            if (edge.cap == 0 || level[edge.to] != level[v] + 1) continue;

            long long pushed = dfs(edge.to, sink, min(flow, edge.cap));
            if (pushed == 0) continue;

            edge.cap -= pushed;
            graph[edge.to][edge.rev].cap += pushed;
            return pushed;
        }
        return 0;
    }

public:
    explicit MaxFlow(int vertex_count)
        : n(vertex_count), graph(vertex_count), level(vertex_count), work(vertex_count) {}

    int add_edge(int from, int to, long long capacity) {
        if (from < 0 || from >= n || to < 0 || to >= n || capacity < 0) {
            throw invalid_argument("invalid max-flow edge");
        }

        int index = static_cast<int>(graph[from].size());
        int reverse_index = static_cast<int>(graph[to].size());
        graph[from].push_back({to, reverse_index, capacity});
        graph[to].push_back({from, index, 0});
        original_edges.push_back({from, index, capacity});
        return static_cast<int>(original_edges.size()) - 1;
    }

    long long max_flow(int source, int sink) {
        if (source < 0 || source >= n || sink < 0 || sink >= n) {
            throw invalid_argument("invalid source or sink");
        }
        if (source == sink) return 0;

        long long result = 0;
        while (bfs(source, sink)) {
            fill(work.begin(), work.end(), 0);
            while (long long pushed = dfs(source, sink, numeric_limits<long long>::max())) {
                result += pushed;
            }
        }
        return result;
    }

    vector<bool> min_cut(int source) const {
        if (source < 0 || source >= n) {
            throw invalid_argument("invalid source");
        }

        vector<bool> reachable(n, false);
        queue<int> q;
        reachable[source] = true;
        q.push(source);

        while (!q.empty()) {
            int v = q.front();
            q.pop();
            for (const Edge &edge : graph[v]) {
                if (edge.cap > 0 && !reachable[edge.to]) {
                    reachable[edge.to] = true;
                    q.push(edge.to);
                }
            }
        }
        return reachable;
    }

    long long get_flow(int edge_id) const {
        if (edge_id < 0 || edge_id >= static_cast<int>(original_edges.size())) {
            throw out_of_range("invalid edge id");
        }

        const OriginalEdge &edge = original_edges[edge_id];
        return edge.capacity - graph[edge.from][edge.index].cap;
    }
};

int n;
long long p0;
pair<long long, long long> one[110], two[110]; // (s, v)

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> p0;
    for (int i = 1; i <= n; i++) {
        cin >> one[i].first;
    }
    for (int i = 1; i <= n; i++) {
        cin >> two[i].first;
    }
    for (int i = 1; i <= n; i++) {
        cin >> one[i].second;
    }
    for (int i = 1; i <= n; i++) {
        cin >> two[i].second;
    }

    // source = 0, sink = n + 1
    MaxFlow max_flow(n + 2);
    long long ans = 0;

    for (int i = 1; i <= n; i++) ans += 2 * p0 * one[i].second;
    for (int i = 1; i <= n; i++) ans += 2 * p0 * two[i].second;
    for (int i = 1; i <= n; i++) {
        max_flow.add_edge(0, i, 2 * p0 * one[i].second);
        max_flow.add_edge(i, n + 1, 2 * p0 * two[i].second);
    }

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (i == j) continue;
            if (
                (one[i].first * one[j].second > one[j].first * one[i].second)
                ||
                (one[i].first * one[j].second == one[j].first * one[i].second && i < j)
            ) { // i < j
                ans += 2 * one[i].first * one[j].second;
                max_flow.add_edge(i, j, one[i].first * one[j].second);
                max_flow.add_edge(j, i, one[i].first * one[j].second);
                max_flow.add_edge(0, i, one[i].first * one[j].second);
                max_flow.add_edge(0, j, one[i].first * one[j].second);
            }
        }
    }

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (i == j) continue;
            if (
                (two[i].first * two[j].second > two[j].first * two[i].second)
                ||
                (two[i].first * two[j].second == two[j].first * two[i].second && i < j)
            ) { // i < j
                ans += 2 * two[i].first * two[j].second;
                max_flow.add_edge(i, j, two[i].first * two[j].second);
                max_flow.add_edge(j, i, two[i].first * two[j].second);
                max_flow.add_edge(i, n + 1, two[i].first * two[j].second);
                max_flow.add_edge(j, n + 1, two[i].first * two[j].second);
            }
        }
    }
    ans -= max_flow.max_flow(0, n + 1);
    cout << ans/2 << endl;

    return 0;
```

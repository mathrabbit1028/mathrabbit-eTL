## 문제 K

문제에서 주어진 것과 비슷하게, 정점 $N = 2m$개에 대해 바깥 $m$개는 한 칸 떨어지게 사이클을 만들고, 안쪽 $m$개는 두 칸 떨어지게 사이클을 만든 후, 안쪽 다각형과 바깥쪽 다각형을 연결하면 된다고 한다. $N$이 홀수이면 차수 합 조건 때문에 불가능하다.

## 문제 D

포인터 `p`, `q`, `r`을 관리하면서 처음으로 어떤 수가 등장하는 위치까지 포인터를 옮기면 common sequence 하나를 얻게 된다. 이때, 가능한 수가 두 종류 뿐임에 착안하면, 전부 $0$인 common sequence 길이와 전부 $1$인 common sequence 길이의 합보다는 실제 LCA 길이가 더 작을 것이다. 따라서 두 가지의 common sequence 길이의 최댓값을 출력하면 된다. 시간복잡도는 $O(N)$이다.

## 문제 I

문자열 길이 $N$에 대해 기대되는 사용량을 $f(N)$이라 두자. 이제 다음 전략을 쓴다:
- `00`, `11`이 나오면 각 배열에 하나씩 넣는다.
- `01`, `10`이 나오면 (일반성을 잃지 않고 `01`이 나온다고 하자)
    + `011`인 경우 `1` 두개를 각 배열에 넣는다.
    + `010`인 경우
        * `0101`인 경우 `01` 두개를 각 배열에 넣는다.
        * `0100`인 경우,
            - `01000`이면 `01`을 버리고 `0` 두개를 각 배열에 넣는다.
            - `01001`이면 `01` 두개를 각 배열에 넣고, `0` 하나를 버린다.

랜덤하게 `0`과 `1`이 뽑히므로,

$$f(N) = \frac{1}{2}[f(N-2) + 2] + \frac{1}{4}[f(N-3) + 2] + \frac{1}{8}[f(N-4) + 4] + \frac{1}{16}[f(N-5) + 2] + \frac{1}{16}[f(N-5) + 4]$$

이 되는데, $f(N) \geq c \cdot N$을 가정하면 $c = 38/45$에서 부등식이 유지되고 이 값은 평균적으로 84.5% 정도의 효율을 준다.

## 문제 H

$a_i > a_{i+1}$의 횟수를 셀 것이다. 다음의 세 가지 경우의 수를 각각 $a$, $b$, $c$라고 하자: 최솟값 $m$에 대해,

- $a$: $2m$보다 작은 수에서 $m$으로 감소하는 경우의 수
- $b$: $2m$에서 $m$으로 감소하는 경우의 수
- $c$: $2m$에서 $m$보다 큰 수로 감소하는 경우의 수

$2m$보다 작은 수에서 $m$보다 큰 수로 감소하는 경우는 $a$ 또는 $c$에 포함시킨다고 가정한다. 그러면 답은 $a + 2b + c$이다.

이제 올라가는 것을 생각해보자. 올라갈 때는 강증가로 올라가기만 하면 되기 때문에, 내려가는 선들을 올라가는 선으로 자연스럽게 이은 모양을 생각하면, $k$가 $c$개 있을 때, 올라가는 부분과 $y=k$의 교점이 $c$개 이상이어야 한다. 따라서,

- $a + b + 1$은 수 $m$의 개수 $S_1$ 이상이어야 한다.
- $a + b + c + 2$는 $m < x < 2m$인 수 중 가장 많은 수의 개수 $S_2$ 이상이어야 한다.
- $b + c + 1$은 $2m$의 개수 $S_3$ 이상이어야 한다.

따라서, 고정된 $b$에 대해 답은 $\max(S_1 + S_3, S_2 + b)$이므로 $b = 0$에서 최적이다. 따라서 답은 $\max(S_1 + S_3, S_2)$이다.

배치의 경우 $S_1 + S_3 = S_2$인 경우에 $a$에 해당하는 경우만 쭉 나열하다가 $m \rightarrow 2m$의 증가를 하나 두고, $c$에 해당하는 경우만 쭉 나열하면 남는 것 없이 다 쓰게 되고, 이것이 최적이다. 따라서, $S_1 + S_3 > S_2$인 경우는 남는 $m$ 또는 $2m$들을 각각 제일 앞과 제일 뒤에 쭉 배치하여도 최적이 보장되고, $S_1 + S_3 < S_2$인 경우는 남는 $m < x < 2m$들을 강증가하는 수열을 최대한 길게 만들어 계속 붙이는 방식으로 나열하면 최적이 보장된다.

시간복잡도는 $O(N)$이다.

## 문제 A

$1$부터 $N$까지 하나씩 넣으면서 종류의 수가 증가하는 시점을 통해 각 그룹의 대표원소 $\text{rep}(i)$는 구할 수 있다. 이제, 두 집합 $S$와 $R$에 대해, $|S| + |R|$번으로 $\{ \text{rep}(i) \mid i \in S \} \subseteq R$의 가정 하에 $\{ \text{rep}(i) \mid i \in S \}$을 구할 수 있다. $S$를 쭉 넣어놓고, $R$을 하나씩 넣을 때 종류의 수가 증가하지 않는 $r \in R$은 $\{ \text{rep}(i) \mid i \in S \}$에 포함된 것이다.

이것을 이용하면 분할정복으로 $\mathcal{O}(N \log N)$에 모든 $\text{rep}(i)$를 구할 수 있다.

## 문제 J

색을 하나씩 채운다고 생각하자. 인접한 정점에 없는 색으로 정하는 경우에는 아무 문제가 없다. 그 어떤 이웃 정점도 조건이 깨지지 않기 때문이다. 그러나 인접한 정점 $u$의 색으로 정하는 경우에는, $u$의 조건이 깨질 수 있다. 따라서, 이 경우에는 $u$를 다시 채워야 한다.

그런데, 즉시 다시 채우게 된다면 잘못 고른 경우에 색 채우기의 순환 고리에 빠질 수도 있고, 애초에 같은 정점의 색을 여러 번 바꾸게 될 수도 있다. 따라서, 다시 채워야 하는 정점들을 `retry`라는 집합에 넣어두고 lazy하게 채우자.

구체적으로는, 일단 모든 정점에 대해 최대한 덜 깨지도록 색을 채운다. 이 후에 `retry`에 들어있는 정점들을 하나씩 꺼내서, 조건이 깨졌다면 다시 가능한 색으로 채운다. 이때, 다시 채워야 할 수도 있는 후보 정점이 생기면 `retry`에 넣어두고, `retry`가 빌 때까지 반복한다.

이 알고리즘은 `retry`의 한 번의 과정이 서로 같은 색을 연결하는 간선의 수가 감소한다는 것으로부터 $O(N + M)$번 반복 후 종료됨을 알 수 있다. 따라서 시간복잡도는 $O(N + M)$이다.

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m;
vector<int> adj[1010101];
int color[1010101];

unordered_set<int> retry;

void fill(int v) {
    int count[5] = {0, 0, 0, 0, 0};
    int vertex[5];

    for (int u : adj[v]) {
        if (color[u] == 0) continue;
        count[color[u]]++;
        vertex[color[u]] = u;
    }

    // no change
    if (color[v] != 0 && count[color[v]] < 2) {
        return;
    }

    for (int c = 1; c <= 4; c++) {
        if (count[c] == 0) {
            color[v] = c;
            return;
        }
    }
    for (int c = 1; c <= 4; c++) {
        if (count[c] == 1) {
            color[v] = c;
            retry.insert(vertex[c]);
            return;
        }
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m;

    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }
    
    for (int v = 1; v <= n; v++) {
        fill(v);
    }

    while (!retry.empty()) {
        int v = *retry.begin();
        retry.erase(retry.begin());
        fill(v);
    }

    for (int i = 1; i <= n; i++) {
        cout << color[i] << " ";
    }
    cout << endl;
}
```

## 문제 F

쿼리가 포인터를 움직이는 것이라는 사실을 상기하자. 즉, 바꾸는 인덱스의 차이의 합은 $\mathcal{O}(Q)$ 스케일이다. 곧, 우리는 포인터의 한 칸 움직일 때마다 특정 작업을 시행하여 변경 쿼리에 대응할 준비를 할 수 있다.

현재 포인터가 $p$일 때, $[1, p)$의 prefix에 대해 LIS의 길이 배열을 관리하고, $(p, N]$의 suffix에 대해 LIS의 길이 배열을 관리하자. 이제, 포인터가 한 칸 움직일 때마다, 세그먼트 트리를 이용하여 ($i$번째 값, $i$까지 prefix/suffix LIS 길이)를 관리하면 된다. $i$번째 값이 수열에 여러 번 등장하는 경우에는 제거하는 업데이트 처리를 위해 LIS 길이의 집합을 저장하면 된다. 리프에서만 집합을 저장하면 충분하기 때문에 시간복잡도와 공간복잡도 상에 문제가 생기지 않는다.

변경 쿼리가 들어왔을 때, 답은 다음의 합이다:
- $p$번째를 포함하는 경우: ($m_i < v$인 $i$들 중에서 prefix LIS 길이의 최댓값) + $1$ + ($v < m_j$인 $j$들 중에서 suffix LIS 길이의 최댓값)
- $p$번째를 포함하지 않는 경우: 모든 값 $x$에 대해, ($m_i < x$인 $i$들 중에서 prefix LIS 길이의 최댓값) + ($x \leq m_j$인 $j$들 중에서 suffix LIS 길이의 최댓값)을 찾으면 된다.

두 번째 경우를 효율적으로 처리하기 위해, $x$에 따른 저 값을 유지하는 배열을 만든다고 생각해보자. 그러면, 포인터가 오른쪽으로 움직일 때,
- prefix LIS 길이 배열에 $(m_i, l_i)$가 추가되었다면, $l_i$의 길이를 갖는 최소 $x$좌표 $m$에 대해, $x-1 \in [m_i, m)$에서 값이 1 증가한다.
- suffix LIS 길이 배열에서 $(m_j, l_j)$가 제거되었다면, $l_j$의 길이를 갖는 최소 $x$좌표 $m$에 대해, $x \in (m, m_j]$에서 값이 1 감소한다.

세그먼트 트리 상에서의 이분탐색과 결합하면, 결국 쿼리당 $\mathcal{O}(\log N)$에 처리할 수 있다.

```cpp
#include <bits/stdc++.h>
using namespace std;

int N, Q, M = 1'000'010;
vector<int> arr;

struct {
    int tree[1<<21];
    map<int, int> mp[1<<21];

    void init(int v, int st, int ed) {
        if (st == ed) {
            tree[v] = 0;
            return;
        }
        int mid = (st + ed) / 2;
        init(v*2, st, mid);
        init(v*2+1, mid+1, ed);
        tree[v] = max(tree[v*2], tree[v*2+1]);
    }

    void add(int v, int st, int ed, int pos, int val) {
        if (st == ed) {
            mp[v][val]++;
            tree[v] = mp[v].rbegin()->first;
            return;
        }
        int mid = (st + ed) / 2;
        if (pos <= mid) add(v*2, st, mid, pos, val);
        else add(v*2+1, mid+1, ed, pos, val);
        tree[v] = max(tree[v*2], tree[v*2+1]);
    }

    void del(int v, int st, int ed, int pos, int val) {
        if (st == ed) {
            mp[v][val]--;
            if (mp[v][val] == 0) mp[v].erase(val);
            tree[v] = mp[v].empty() ? 0 : mp[v].rbegin()->first;
            return;
        }
        int mid = (st + ed) / 2;
        if (pos <= mid) del(v*2, st, mid, pos, val);
        else del(v*2+1, mid+1, ed, pos, val);
        tree[v] = max(tree[v*2], tree[v*2+1]);
    }

    int query(int v, int st, int ed, int l, int r) {
        if (l > r) return 0;
        if (st >= l && ed <= r) return tree[v];
        int mid = (st + ed) / 2;
        return max(query(v*2, st, mid, l, min(r, mid)),
                   query(v*2+1, mid+1, ed, max(l, mid+1), r));
    }

    int min_pos(int v, int st, int ed, int lower) {
        if (tree[v] < lower) return ed + 1;
        if (st == ed) return st;
        int mid = (st + ed) / 2;
        if (tree[2 * v] >= lower) return min_pos(2 * v, st, mid, lower);
        else return min_pos(2 * v + 1, mid + 1, ed, lower);
    }

    int max_pos(int v, int st, int ed, int lower) {
        if (tree[v] < lower) return st - 1;
        if (st == ed) return st;
        int mid = (st + ed) / 2;
        if (tree[2 * v + 1] >= lower) return max_pos(2 * v + 1, mid + 1, ed, lower);
        else return max_pos(2 * v, st, mid, lower);
    }
    
} prefix, suffix;

struct {
    int tree[1<<21], lazy[1<<21];

    void init(int v, int st, int ed, vector<int> &vec) {
        if (st == ed) {
            tree[v] = vec[st];
            return;
        }
        int mid = (st + ed) / 2;
        init(v*2, st, mid, vec);
        init(v*2+1, mid+1, ed, vec);
        tree[v] = max(tree[v*2], tree[v*2+1]);
    }

    void update(int v, int st, int ed, int l, int r, int val) {
        if (lazy[v]) {
            tree[v] += lazy[v];
            if (st != ed) {
                lazy[v*2] += lazy[v];
                lazy[v*2+1] += lazy[v];
            }
            lazy[v] = 0;
        }
        if (l > r) return;
        if (st >= l && ed <= r) {
            tree[v] += val;
            if (st != ed) {
                lazy[v*2] += val;
                lazy[v*2+1] += val;
            }
            return;
        }
        int mid = (st + ed) / 2;
        update(v*2, st, mid, l, min(r, mid), val);
        update(v*2+1, mid+1, ed, max(l, mid+1), r, val);
        tree[v] = max(tree[v*2], tree[v*2+1]);
    }

    int query(int v, int st, int ed, int l, int r) {
        if (lazy[v]) {
            tree[v] += lazy[v];
            if (st != ed) {
                lazy[v*2] += lazy[v];
                lazy[v*2+1] += lazy[v];
            }
            lazy[v] = 0;
        }
        if (l > r) return 0;
        if (st >= l && ed <= r) return tree[v];
        int mid = (st + ed) / 2;
        return max(query(v*2, st, mid, l, min(r, mid)),
                   query(v*2+1, mid+1, ed, max(l, mid+1), r));
    }

} length;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> N >> Q;
    for (int i = 0; i < N; i++) {
        int x;
        cin >> x;
        arr.push_back(x);
    }

    for (int i = N - 1; i > 0; i--) {
        int l = suffix.query(1, 0, M, arr[i] + 1, M) + 1;
        suffix.add(1, 0, M, arr[i], l);
    }
    vector<int> vec;
    for (int i = 0; i <= M; i++) {
        vec.push_back(suffix.query(1, 0, M, i, M));
    }
    length.init(1, 0, M, vec);

    int pointer = 0;
    while (Q--) {
        char c;
        cin >> c;
        if (c == '>') {
            int l, m;
            l = prefix.query(1, 0, M, 1, arr[pointer] - 1) + 1;
            m = prefix.min_pos(1, 0, M, l);
            prefix.add(1, 0, M, arr[pointer], l);
            length.update(1, 0, M, arr[pointer]+1, m, +1);
            pointer++;
            l = suffix.query(1, 0, M, arr[pointer] + 1, M) + 1;
            suffix.del(1, 0, M, arr[pointer], l);
            m = suffix.max_pos(1, 0, M, l);
            length.update(1, 0, M, m+1, arr[pointer], -1);
        } else if (c == '<') {
            int l, m;
            l = suffix.query(1, 0, M, arr[pointer] + 1, M) + 1;
            m = suffix.max_pos(1, 0, M, l);
            suffix.add(1, 0, M, arr[pointer], l);
            length.update(1, 0, M, m+1, arr[pointer], +1);
            pointer--;
            l = prefix.query(1, 0, M, 1, arr[pointer] - 1) + 1;
            prefix.del(1, 0, M, arr[pointer], l);
            m = prefix.min_pos(1, 0, M, l);
            length.update(1, 0, M, arr[pointer]+1, m, -1);
        } else {
            cin >> arr[pointer];
            int ans = length.query(1, 0, M, 1, M);
            ans = max(ans,
                prefix.query(1, 0, M, 1, arr[pointer] - 1) + 1 + suffix.query(1, 0, M, arr[pointer] + 1, M)
            );
            cout << ans << "\n";
        }
    }
}
```

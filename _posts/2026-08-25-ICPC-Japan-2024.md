## 문제 I

주어진 쿼리는 구간 $A_l, A_{l+1}, \cdots, A_r$에서 $d$의 배수가 두 개 이상인 가장 큰 $d$를 찾는 것과 동치다. 수의 범위가 $10^5$ 이하이므로 $10^5$까지의 각 자연수의 배수의 개수를 배열로 저장한다고 하자. 이 배열은 구간의 길이가 1씩 변동될 때마다 상수 시간에 업데이트할 수 있고, 답은 **구간이 늘어나는 경우**에 상수 시간에 업데이트할 수 있다.

따라서 mo's 알고리즘을 쓰자. 시작점이 특정 구간 안에 있는 쿼리들을 끝점이 증가하는 순으로 모아서, 구간의 길이가 변동되는 횟수를 $\mathcal{O}((N + Q) \sqrt{N})$로 줄이는 것이다. 이때, 구간이 감소할 때는 답을 유지할 수 없기 때문에, 시작점을 찾기 위해서 구간을 늘렸다가 줄일 때는, 구간을 늘리기 전의 답을 따로 저장해두자.

## 문제 D

문제의 조건에 따라 각 `1`이 나타내는 정점의 번호는 문자 `1`이 등장한 번째와 같다. 따라서 이제 문자 `1`을 *몇 번 정점*이라 부르겠다. 그러면, `(S T)` 꼴의 부분 문자열이 만들어낼 수 있는 트리의 자유도는
- `S`에 $l$번 정점부터 $x$번 정점까지 있고,
- `T`에 $x+1$번 정점부터 $r$번 정점까지 있다면,
`S`와 `T` 각각의 자유도의 곱에 $(x-l+1)(r-x)$를 곱한 값이다. 왜냐하면 $x$가 포함된 컴포넌트와 $x+1$이 포함된 컴포넌트의 연결은 $l \leq v \leq x$와 $x+1 \leq u \leq r$인 정점 $v, u$를 통해서만 가능하기 때문이다.

이것은 사실상 트리 형태의 제약조건과 같다. 곧, 2개의 트리 표현식으로 동시에 표현가능한 트리는 상술된 제약조건을 동시에 만족하는 트리라는 뜻이다. 즉, 각각의 트리 표현식에서 $x$에 따른 $l, r$를 구하고, 최솟값을 취하면 된다. 정확히, 첫 번째 표현식에서 $l_1, r_1$이 나오고 두 번째 표현식에서 $l_2, r_2$가 나오면, $l = \max(l_1, l_2)$, $r = \min(r_1, r_2)$이다.

$l$과 $r$을 찾는 것은 stack을 이용하여 $\mathcal{O}(N)$에 가능하다. 따라서 전체 시간복잡도는 $\mathcal{O}(N)$이다.  

## 문제 K

$a_{i,\cdot}$가 주어졌다고 하자. 그러면 `N`이 적힌 칸에는 적어도 `Y`가 적혀 있는 $a_{j,\cdot}~(j < i)$들 중에서 적힌 `Y`의 개수가 가장 많은 것을 찾아야 한다. 만약 그것도 같다면 $j$가 가장 작은 것을 찾아야 한다. 이것을 할 수 있다면 문제는 풀린다: 우리는 $a_{i,\cdot}$와 $a_{j,\cdot}$에 적혀 있는 총 `Y`의 개수, $j$, $i$ 순으로 비교하여 가장 앞선 것을 답으로 출력하면 된다.

이제, 단순화를 위해 `Y`를 비트 `1`로, `N`을 비트 `0`으로 바꾸자. 그러면 $a_{i,\cdot}$는 길이 $m$의 비트열이 된다. 이제, meet-in-the-middle과 비슷한 방식으로 하자. $a_{j,\cdot}$의 앞 $m/2$의 인덱스에 매핑된 리스트를 찾아서, $a_{j,\cdot}$의 뒤 $m/2$에 해당하는 비트의 subset 인덱스마다 (`1`의 개수, $j$)를 저장한다. 이 과정의 총 시간복잡도는 $\mathcal{O}(n 2^{m/2})$이다.

이걸 해 놓으면, $a_{i, \cdot}$가 주어질 때마다, 보수의 앞 $m/2$에 해당하는 비트의 superset 인덱스들에 매핑된 리스트 $\mathcal{O}(2^{m/2})$개를 탐색하여, 보수의 뒤 $m/2$에 해당하는 비트의 (`1`의 개수, $j$)만을 고려하면 충분하다. 이것 역시 총 시간복잡도는 $\mathcal{O}(n 2^{m/2})$이다. 

따라서 전체 시간복잡도는 $\mathcal{O}(n 2^{m/2})$이다.

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m;
vector<bitset<20>> vec;
pair<int, int> arr[1<<10][1<<10];

bool update(pair<int, int> &dest, pair<int, int> val) {
    if (dest.first == -1 || val.first > dest.first) {
        dest = val;
        return true;
    } else if (val.first == dest.first) {
        dest.second = min(dest.second, val.second);
        return true;
    }
    return false;
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(0);

    cin >> n >> m;
    for (int i = 0; i < n; i++) {
        bitset<20> bits;
        for (int j = 0; j < m; j++) {
            char c;
            cin >> c;
            bits[j] = (c == 'N') ? 0 : 1;
        }
        vec.push_back(bits);
    }

    int f = m/2, b = m - f;

    for (int i = 0; i < (1 << f); i++) {
        for (int j = 0; j < (1 << b); j++) {
            arr[i][j] = {-1, 0};
        }
    }

    int _max = 0;
    pair<int, int> ans = {n, n};
    for (int i = 0; i < n; i++) {
        bitset<10> front, back;

        for (int j = 0; j < f; j++) front[j] = 1 - vec[i][j];
        for (int j = f; j < m; j++) back[j - f] = 1 - vec[i][j];
        for (int mask = 0; mask < (1 << f); mask++) {
            bitset<10> mask_bits(mask);
            if ((mask_bits & front) == front) {
                if (arr[mask][back.to_ulong()].first == -1) continue;
                int cnt = vec[i].count() + mask_bits.count() + arr[mask][back.to_ulong()].first;
                if (cnt > _max) {
                    _max = cnt;
                    ans = {arr[mask][back.to_ulong()].second, i};
                } else if (cnt == _max) {
                    ans = min(ans, {arr[mask][back.to_ulong()].second, i});
                }
            }
        }

        for (int j = 0; j < f; j++) front[j] = vec[i][j];
        for (int j = f; j < m; j++) back[j - f] = vec[i][j];
        for (int mask = 0; mask < (1 << b); mask++) {
            bitset<10> mask_bits(mask);
            if ((mask_bits | back) == back) {
                update(arr[front.to_ulong()][mask], {back.count(), i});
            }
        }
    }

    if (ans.first == n) {
        cout << "No\n";
    } else {
        cout << ans.first + 1 << " " << ans.second + 1 << "\n";
    }
}
```

# 문제 1 (Festival)

## subtask 5

전부 살 수 있다면 그리디하게 남은 토큰의 수가 더 많도록 순서를 정하면 된다. $(T_1, P_1)$과 $(T_2, P_2)$가 있을 때, 처음 토큰에 $A$개 있었다면,

- $1 \rightarrow 2$ 순서로 사는 경우
$$((A - P_1) \cdot T_1 - P_2) \cdot T_2 = T_1 T_2 A - T_1 T_2 P_1 - T_2 P_2$$
- $2 \rightarrow 1$ 순서로 사는 경우
$$((A - P_2) \cdot T_2 - P_1) \cdot T_1 = T_1 T_2 A - T_1 P_1 - T_1 T_2 P_2$$

이므로, $T_1 T_2 P_1 + T_2 P_2 < T_1 P_1 + T_1 T_2 P_2$를 만족하면 $1 \rightarrow 2$ 순서가 더 좋다. 즉, $1$이 $2$보다 앞일 필요충분조건은

$$P_1 T_1 (T_2 - 1) < P_2 T_2 (T_1 - 1) \iff \frac{T_1}{T_1-1}P_1 < \frac{T_2}{T_2-1}P_2$$

이다. 이것은 쿠폰의 손익분기점 순으로 정렬하면 된다는 뜻이기도 하다. 단, $T_1 = T_2 = 1$인 경우만 가격이 더 낮은 것을 우선해야 한다.

## $\mathcal{O}(N^2)$

정렬을 하고 나면 문제는 각 쿠폰의 사용 여부를 정하는 문제가 된다. 따라서, $i$번째 쿠폰부터 $x$개 이상을 소비하기 위해 필요한 최소 토큰 개수를 $dp[i][x]$라 정의하고 나면,

$$\begin{align*} dp[i][x] &\leftarrow dp[i+1][x] \\ dp[i][x] &\leftarrow \left\lceil \frac{dp[i+1][x-1]}{T_i} \right\rceil + P_i \end{align*}$$

의 전이식이 성립한다. 초깃값은 $dp[N][0] = 0$이고 $dp[N][x] = \infty$ for $x > 0$이다. 이때, $dp[0][x] \leq A$인 최대 $x$가 정답이 된다. 실제 사용해야 할 쿠폰을 찾는 과정은 심플한 tracing이므로 생략한다.

## 만점 풀이

정렬한 후 구간을 세 페이즈로 나누자:
- Phase 1 : 토큰이 감소하지 않는 구간
- Phase 2 : 토큰이 감소하지만, $T_i > 1$인 구간
- Phase 3 : $T_i = 1$인 구간

정렬 규칙에 따라 모든 정렬 결과는 위의 세 페이즈로 나누어짐을 보일 수 있다.

### Phase 1

이 페이즈의 쿠폰은 쓰지 않을 이유가 없다. 따라서 항상 사용한다. 숫자가 매우 커질 수 있음에 유의해야 한다; 그냥 $N \cdot 10^9$보다 커지면 뒤 쿠폰을 무조건 전부 다 살 수 있으므로 끝내면 된다.

### Phase 2

Phase 2의 시작 토큰 번호를 $l$이라 하자. 그리고 Phase 1의 결과로 나온 토큰 수를 $A_l$이라 하자. 이제 같은 dp를 하면 되는데, 이 경우 $x \leq \log_2 (2 \cdot 10^9)$ 정도만 고려해도 충분하다. 그 이유는:
- 현재 손익분기점 $K_l$와의 차이 $K_l - A_l$에 대해, 쿠폰을 사용한 후의 토큰 $A_{l+1}$는
$$K_l - A_{l+1} = T_i (K_l - A_l) \geq 2 (K_l - A_l)$$
를 만족시킨다.
- 손익분기점은 단조증가하므로 
$$K_{l+1} - A_{l+1} \geq K_l - A_{l+1} \geq 2 (K_l - A_l)$$
를 만족시킨다. 

이것은, 현재의 손익분기점과 현재의 토큰 개수의 차이가 적어도 두 배씩 증가함을 의미하고, 손익분기점은 최대 $2 \cdot 10^9$이므로, Phase 2에서 고려해야 할 쿠폰의 개수는 $\log_2 2 \cdot 10^9$ 이하이다.

이렇게 되면 대략 $30N$ 정도의 시간복잡도의 dp를 돌리면 돼서 충분히 해결할 수 있다.

### Phase 3

Phase 3은 dp의 초깃값을 결정하는 부분이다. Phase 3의 시작 쿠폰 번호 $r$에 대해,
$$dp[r][x] = \sum_{i=r}^{r+x-1} P_i$$
이다. 이것을 먼저 처리하고 Phase 2의 dp를 돌리면 된다. Phase 3은 단순히 prefix sum을 구하면 되므로, 시간복잡도는 $O(N)$이다.

```cpp
#include "festival.h"
#include <bits/stdc++.h>
using namespace std;

struct Coupon {
    long long p;
    int t;
    int i;
    bool operator<(const Coupon &other) const {
        if (p * t * (other.t - 1) == other.p * other.t * (t - 1)) {
            return p < other.p;
        } else {
            return p * t * (other.t - 1) < other.p * other.t * (t - 1);
        }
    }
} coupons[202020];

long long dp[202020][32];

vector<int> max_coupons(int A, vector<int> P, vector<int> T) {
    vector<int> ans;

    for (int i = 0; i < P.size(); i++) {
        coupons[i] = {P[i], T[i], i};
    }
    sort(coupons, coupons + P.size());

    int l = 0, r = 0;
    long long befA = A;
    while (l < P.size()) {
        long long a = (befA - coupons[l].p) * coupons[l].t;
        if (a >= 1e17) {
            while (l < P.size()) {
                ans.push_back(coupons[l].i);
                l++;
            }
            return ans;
        }
        if (a >= befA) {
            ans.push_back(coupons[l].i);
            l++;
            befA = a;
        }
        else break;
    }

    while (r < P.size()) {
        if (coupons[r].t != 1) r++;
        else break;
    }
    vector<long long> prefix_1;
    for (int i = r; i < P.size(); i++) {
        prefix_1.push_back(coupons[i].p);
    }
    for (int i = 1; i < prefix_1.size(); i++) {
        prefix_1[i] += prefix_1[i-1];
    }

    // start with l, end with r-1
    for (int m = 1; m < 32; m++) dp[l][m] = -1;
    dp[l][0] = befA;
    for (int i = l; i < r; i++) {
        for (int m = 0; m < 32; m++) {
            dp[i+1][m] = dp[i][m];
        }
        for (int m = 0; m < 31; m++) {
            if (dp[i][m] - coupons[i].p >= 0) {
                dp[i+1][m+1] = max(dp[i+1][m+1], (dp[i][m] - coupons[i].p) * coupons[i].t);
            }
        }
    }

    int num = 0, val = 0;
    for (int m = 0; m < 32; m++) {
        long long rem = dp[r][m];
        if (rem < 0) continue;
        int add = upper_bound(prefix_1.begin(), prefix_1.end(), rem) - prefix_1.begin();
        if (m + add >= val) {
            num = m;
            val = m + add;
        }
    }
    int _num = num;
    for (int i = r - 1; i >= l; i--) {
        if (dp[i][_num] == dp[i+1][_num]) continue;
        _num--;
        ans.push_back(coupons[i].i);
    }
    reverse(ans.begin() + ans.size() - num, ans.end());
    for (int i = r; i < r + val - num; i++) {
        ans.push_back(coupons[i].i);
    }
    return ans;
}

```

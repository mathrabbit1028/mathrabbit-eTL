## 문제 H

DFS를 돌리면서:
- 자식이 없는 경우, 아무것도 하지 않아도 된다.
- 자식이 한 개인 경우, 한쪽 자식의 서브트리에서 깊이가 1보다 큰 부분은 전부 쳐내야 한다.
- 자식이 두 개인 경우, 자식이 더 많은 서브트리에서 차이가 1보다 큰 부분은 전부 쳐내야 한다.

이것은 DFS에서 서브트리의 깊이에 따라 존재하는 노드의 수를 반환하면 쉽게 구현할 수 있다. 참고로, 깊이가 1보다 많이 차이나면 지우기 때문에 각 정점마다 리턴되는 배열의 길이는 $\mathcal{O}(\log N)$이고, 곧 전체 시간복잡도는 $\mathcal{O}(N \log N)$이다.

## 문제 J

자신이 포함되는 구간에 부여된 수들의 최댓값에 1을 더한 값을 구하면 된다. 따라서, 먼저 구간들을 시점이 커지는 순으로, 시점이 같다면 끝점이 작아지는 순으로 정렬하자. 이 순서대로 값을 정하면
- 각 구간에 대해 자신이 포함될 수 있지만 고려되지 않는 구간은 없다.
- 현재 구간 $(l, r)$에 대해 $r$ 이상의 끝점을 가지는 구간들에 부여된 수의 최댓값을 찾으면 충분하다.
- 세그먼트 트리로 최댓값을 찾고, $(l, r)$의 값을 $r$에 업데이트하면 된다.

구간 범위가 넓으므로 좌표압축을 하고 시작하자. 전체 시간복잡도는 $\mathcal{O}(N \log N)$이다.

## 문제 E

$1$번 정점을 포함해 거리가 $i$인 점의 개수를 $c_i$라 하면, 모든 그래프는 다음을 만족한다:
- $c_0 = 1$
- $\forall i < j$, $c_j \neq 0 \implies c_i \neq 0$
- $\sum_{i=0}^{N-1} c_i = N$

또한, 위 조건을 만족시키는 모든 $(c_0, c_1, \ldots, c_{N-1})$에 대해 그래프를 만들 수 있다 (루트가 $1$번인 트리로 만들면 된다).

그리고 우리의 목표는

$$\sum_{i=0}^{N-1} i \cdot c_i = a \cdot \frac{N}{b}$$

을 만족시키는 $(c_0, c_1, \ldots, c_{N-1})$를 찾는 것이다. 이때, $a$와 $b$는 주어진다. 또한 이하의 논의에서 $a$와 $b$가 서로소가 아니면 최대공약수로 나누어 서로소로 만들었다고 가정하겠다.

$N$을 고정했다고 생각하자. 그리고 $c_i$까지 결정했다고 생각하자:
- 남은 것을 전부 $c_{i+1}$로 두어도 거리가 원하는 값보다 초과한다면, 불가능한 것이다.
- 남아있는 정점들을 생각했을 때, $c_{i+1}$와 $c_{i+2}$만으로 완성할 수 있는 경우에는, 수학적으로 계산해서 완성시키면 된다.
- 그렇지 못한 경우에는, 아직 채워야 하는 거리가 많이 남았다는 뜻이므로 $c_{i+1} = 1$로 최대한 작게 둔다.

이 방법으로 고정된 $N$에 대해 가능한지 판별하고, 가능하다면 그래프를 만들 수 있다.

한편, 모든 $N$에 대해 시도하면 $N \leq 10^6$에서 시도해야 할 $N$이 너무 많다. 하지만, 생각해보면 가능한 최솟값이 가장 작은 $N$과 가능한 최댓값이 가장 큰 $N$만 시도해도 충분하다.
- 최솟값은 언제 가능할까? $c_0 = 1$이고 $c_1 = N-1$인 경우이다. 이때의 평균거리는 $N$이 작을수록 작아지기 때문에, $N = b$를 시도해야 한다.
- 최댓값은 언제 가능할까? $c_0 = c_1 = \cdots = c_{N-2} = 1$인 경우이다. 이때의 평균거리는 $N$이 커질수록 커지기 때문에, $N$을 $b$에 배수 중에 $10^6$ 이하인 수 중에서 가장 큰 수를 시도해야 한다.

따라서, $2 \cdot 10^6$ 정도의 시간에 문제를 해결할 수 있다.

## 문제 G

길이를 모르지만, 어떤 길이 $L$이 아니라는 것은 쉽게 알 수 있다:
- 빛을 바꾸지 않았을 때, 어떤 $i$에 대해, $i$번째와 $i + Lq$번째로 관측된 불빛이 다르다면 답이 $L$이 아니다.

따라서, $L = 3$부터 시작하면서 답이 될 수 없다면 $L$을 1씩 증가시키면서 답을 찾으면 된다. 이때, 의도적으로 초기 상태에 규칙이 있어서 답이 틀리게 나올 수 있다. 따라서, 한 바퀴 돌아서 모순이라는 증거를 찾지 못했다면 다음 번 반복에서는 랜덤하게 $L$개의 빛을 설정하고 다시 시도해야 한다. 구체적으로는 다음의 알고리즘을 사용하면 충분히 $3n + 500$번 이하의 반복으로 답을 찾을 수 있다:

1. $L = 3$부터 시작한다.
2. 무조건 처음 $L$개의 빛을 랜덤하게 설정한다.
3. 이후에 최대 $L$번 빛이 일치하는지 확인한다.
    - 일치하지 않으면, 답이 될 수 있는 가장 작은 $L$을 찾는다; 이것은 현재의 데이터로 $L+1$ 등이 불가능하다는 것을 알아낼 수 있는 경우에 이 정보를 사용하여 쿼리 사용 횟수를 줄이기 위함이다. 이후 2번으로 돌아간다.
    - 일치하면, $L$을 늘리지 않고 2번으로 돌아간다.

이 알고리즘을 사용하면 제한을 넘기기 직전에, 현재의 $L$의 값이 답일 확률이 충분히 높다. 따라서 쿼리 사용 횟수를 세서 누적하고, 제한에 근접해지면 현재 $L$을 출력하고 종료하면 된다.

## 문제 K

$K$개의 정점과 $N$개의 간선이 있는 것으로 모델링하자. 한 피자 위에 $a$와 $b$번 토핑이 놓인 것은 $(a, b)$라는 간선이 존재하는 것이다. 그러면 아주 중요한 아이디어를 얻을 수 있는데:
> (러프하게 말하면) 문제에서 원하는 조건을 만족시킨다면 임의의 정점에 대해서 연결된 다른 정점들 중에 degree가 2 이상인 정점이 두 개 이하여야 한다.

그 이유는 
- 현재 정점을 $v$라고 하자.
- $v$와 연결된 정점 $u$가 degree가 2 이상이라는 것은, $(v, u)$ 피자 조각 옆에 $v$는 들어가지 않지만 $u$가 들어가는 피자 조각이 위치해야 한다는 뜻이고, 그러면 $v$가 포함된 피자조각 구간의 끝에 $(v, u)$가 위치해야 한다는 것이다.
- 따라서 구간의 끝은 많아야 두 개이기 때문에, 이러한 정점들은 최대 두 개만 존재할 수 있다.

한편, 어떤 컴포넌트가 사이클을 이룬다면 문제가 생길 수 있다. 사이클이 존재하면 그 사이클 안에 있는 간선들을 피자에 배치하는 것으로 피자의 한 바퀴가 다 채워지기 때문에, 다른 컴포넌트에 있는 어떤 간선도 피자에 배치할 수 없기 때문이다. 이 모든 것을 종합하면 정확한 알고리즘은 다음의 순서를 따른다:
1. 일단 중복 간선은 제거해도 된다. 피자 조각을 반으로 자르면 되기 때문이다. 따라서 **self-loop** 두 개도 중복 간선이다.
2. **self-loop**를 포함하여 차수를 셌을 때, degree가 0인 정점은 지운다. 피자에 나오지 않기 때문이다.
3. **self-loop**를 포함하여 차수를 세어서, 각 정점과 연결된 degree가 2 이상인 정점이 두 개 이하인지 확인한다. 만약 **어떤 정점**에 대해 세 개 이상이면, 답은 "NO"이다.
    - **self-loop**를 포함하는 이유는, (1, 2), (2, 2)가 있을 때 (1, 2)가 바깥으로 가야 하기 때문이다.
4. 최종 정답은 길이 3 이상의 사이클의 존재 여부에 따라 달라진다:
    - 사이클이 존재하면(3번에 의해 둘 이상은 없다), 컴포넌트가 하나인 경우에는 답은 "YES"이다. 컴포넌트가 둘 이상이면 답은 "NO"이다.
        + self-loop가 있는 크기 1의 컴포넌트도 유효한 컴포넌트로 세야 한다.
    - 사이클이 없다면, 답은 "YES"이다.

시간복잡도는 $\mathcal{O}(N + K)$이다.

## 문제 L

### Part 1: 정보 단순화

주어진 조건은 항상 다음의 꼴로 쓰여진다:
- **정답 문자열**의 각 칸에 들어올 수 있는 알파벳의 집합 $S_i \subseteq \lbrace \mathrm{a}, \mathrm{b}, \mathrm{c}, \ldots, \mathrm{z} \rbrace$가 주어진다.
- **정답 문자열**에 각 알파벳은 $l_i$번 이상, $r_i$번 이하로 등장해야 한다. $(\mathrm{a} \leq i \leq \mathrm{z})$

간단히 로직을 설명하자면
- 초록색으로 표시된 칸은 반드시 해당 알파벳이 들어가야 한다. 즉, $S_i$가 단일 원소 집합이 된다.
- 노란색 혹은 검은색으로 표시된 칸은 해당 알파벳이 들어갈 수 없다. 즉, $S_i$에서 해당 알파벳을 지운다.
- 각 쿼리에 대해, **쿼리 문자열**에 알파벳 $i (\mathrm{a} \leq i \leq \mathrm{z})$가 있는 위치에 초록색, 노란색, 검은색 수를 각각 $g, y, b$라 두면
    + $b = 0$인 경우에 하한 $g+y$가 주어진 것이다.
    + $b > 0$인 경우에는 개수가 정확히 $g+y$개라는 사실이 주어진 것이다.

### Part 2: 빈칸 채우기

이제 빈칸과 문자열 사이의 매칭 문제로 바꾸자. 먼저 그래프를 다음과 같이 디자인하자:
- 왼쪽은 $l$개의 빈칸이다.
- 오른쪽은 $26$개의 알파벳이다. 각 알파벳은 각 알파벳이 등장할 수 있는 최대 개수만큼 복제해서 정점으로 만든다. 여기서 $r_i$에 대한 조건이 없는 경우에는 임의로 $r_i = l$로 두면 된다.

그러면 빈칸 채우기는 이분 그래프의 매칭이 된다. 그런데, 그냥 이렇게 이분매칭을 하면 하한 조건을 만족시킨다는 보장이 없다. 놀랍게도 이것은 Augmenting Path을 쓰는 이분 매칭으로 해결할 수 있는데, 그 이유는 이 알고리즘에서 새로운 매칭 가능성을 찾을 때 원래 매칭된 정점 집합이 $S$이고, 나중에 매칭된 정점 집합이 $T$라면 $S \subseteq T$이기 때문이다. 그러니까, 하한 조건을 만족시키는 매칭을 찾고, 그 이후에 매칭을 늘리는 과정에서 하한 조건을 깨뜨리지 않는다. 그리고 하한 조건을 만족시키는 매칭은, 오른쪽에 정점을 최소 개수만큼 복제해서 놓으면 찾을 수 있다. 정리하면,

1. STEP 1: 각 알파벳 $i$에 대해, $l_i$만큼 복제해서 오른쪽에 정점을 놓는다. 그리고 이분 매칭을 돌려서, 알파벳에 대응되는 모든 정점이 매칭되도록 한다. 문제에서 가능함 문자열이 존재한다고 했으므로 이것이 불가능할 수 없다.
2. STEP 2: 각 알파벳 $i$에 대해, $r_i - l_i$만큼 복제해서 오른쪽에 정점을 **추가로** 놓는다. 그리고 **Augmenting Path** 기반 이분 매칭을 돌려서, 모든 빈칸이 매칭되도록 한다. 문제에서 가능함 문자열이 존재한다고 했으므로 이것이 불가능할 수 없다.

시간복잡도는 엄밀하게는 $\mathcal{O}(l^3 \cdot 26)$이지만 실제로 그렇게 오래 걸리지 않는다.

## 문제 F

네 가지 경우가 있다:
1. 직선이 $x$축과 평행한 경우에는, $[y_1, y_2]$ 모두에 속하는 $y$좌표가 존재하는지 확인하면 된다.
2. 직선이 $y$축과 평행한 경우에는, $[x_1, x_2]$ 모두에 속하는 $x$좌표가 존재하는지 확인하면 된다.
3. 직선의 기울기가 양인 경우에는, $[y_1 - x_2 \cdot m, y_2 - x_1 \cdot m]$ 모두에 속하는 $y$좌표가 존재하는 $m$이 있는지 확인하면 된다. 이 과정은 하한의 $\max$를 나타내는 convex hull과, 상한의 $\min$을 나타내는 convex hull을 만들어서, 각 convex hull의 선분에 대해 하한 이상 상한 이하의 점이 존재하는지 확인하면 된다. 존재 여부는 두 선분의 교점이 $x$범위 왼쪽인지 오른쪽인지 확인하면 된다.
4. 직선의 기울기가 음인 경우에는, $[y_1 + x_1 \cdot m, y_2 + x_2 \cdot m]$ 모두에 속하는 $y$좌표가 존재하는 $m$이 있는지 확인하면 된다. 이 과정은 위와 동일하다.

네 경우 모두에서 가능한 직선을 발견하지 못하면 불가능하다. 시간복잡도는 $\mathcal{O}(N \log N)$이다. 교점은 유리수이므로 실수오차 방지를 위해 모든 교점의 $x$좌표는 분수를 나타내는 구조체로 관리하였다.

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
struct rect {
    int x1, x2, y1, y2;
} rects[202020];

void solve_0() {
    int lw = -2e9, up = 2e9;
    for (int i = 0; i < n; i++) {
        lw = max(lw, rects[i].y1);
        up = min(up, rects[i].y2);
    }
    if (lw <= up) {
        cout << "possible\n";
        exit(0);
    }
}

void solve_90() {
    int lw = -2e9, up = 2e9;
    for (int i = 0; i < n; i++) {
        lw = max(lw, rects[i].x1);
        up = min(up, rects[i].x2);
    }
    if (lw <= up) {
        cout << "possible\n";
        exit(0);
    }
}

struct frac {
    int num, den; // den > 0
    bool operator<(const frac &o) const {
        assert(den > 0 && o.den > 0);
        return 1LL * num * o.den < 1LL * o.num * den;
    }
    bool operator<=(const frac &o) const {
        assert(den > 0 && o.den > 0);
        return 1LL * num * o.den <= 1LL * o.num * den;
    }
    bool operator>(const frac &o) const {
        assert(den > 0 && o.den > 0);
        return 1LL * num * o.den > 1LL * o.num * den;
    }
    bool operator>=(const frac &o) const {
        assert(den > 0 && o.den > 0);
        return 1LL * num * o.den >= 1LL * o.num * den;
    }
};
struct line {
    int m;
    int b;
    frac st, ed;
    line() : m(0), b(0), st({0, 1}), ed({0, 1}) {}
    line(int m, int b, frac st, frac ed) : m(m), b(b), st(st), ed(ed) {}
};
frac intersect(const line &a, const line &b) {
    if (a.m == b.m) assert(false);
    if (a.m > b.m) return {b.b - a.b, a.m - b.m};
    else return {a.b - b.b, b.m - a.m};
}

void solve_plus() {
    vector<line> lines;

    // upper envelope of lines y = -x + b
    for (int i = 0; i < n; i++) {
        lines.push_back(line{-rects[i].x2, rects[i].y1, frac{(int)-2e9, 1}, frac{(int)2e9, 1}});
    }
    sort(lines.begin(), lines.end(), [](const line &a, const line &b) {
        if (a.m == b.m) return a.b < b.b;
        return a.m < b.m;
    });
    deque<line> deq;
    for (const auto &l : lines) {
        frac st = {(int)-2e9, 1};
        while (!deq.empty()) {
            line last = deq.back();
            if (last.m == l.m) deq.pop_back();
            else {
                st = intersect(last, l);
                if (st <= last.st) {
                    deq.pop_back();
                } else {
                    deq.pop_back();
                    last.ed = st;
                    deq.push_back(last);
                    break;
                }
            }
        }
        deq.push_back({l.m, l.b, st, frac{(int)2e9, 1}});
    }
    vector<line> lower = vector<line>(deq.size());
    for (int i = 0; !deq.empty(); i++) {
        lower[i] = deq.front();
        deq.pop_front();
    }

    // lower envelope of lines y = -x + b
    lines.clear();
    for (int i = 0; i < n; i++) {
        lines.emplace_back(-rects[i].x1, rects[i].y2, frac{(int)-2e9, 1}, frac{(int)2e9, 1});
    }
    sort(lines.begin(), lines.end(), [](const line &a, const line &b) {
        if (a.m == b.m) return a.b > b.b;
        return a.m > b.m;
    });
    for (const auto &l : lines) {
        frac st = {(int)-2e9, 1};
        while (!deq.empty()) {
            line last = deq.back();
            if (last.m == l.m) deq.pop_back();
            else {
                st = intersect(last, l);
                if (st <= last.st) {
                    deq.pop_back();
                } else {
                    deq.pop_back();
                    last.ed = st;
                    deq.push_back(last);
                    break;
                }
            }
        }
        deq.push_back({l.m, l.b, st, frac{(int)2e9, 1}});
    }
    vector<line> upper = vector<line>(deq.size());
    for (int i = 0; !deq.empty(); i++) {
        upper[i] = deq.front();
        deq.pop_front();
    }

    int p = 0, q = 0;
    while (p < lower.size() && q < upper.size()) {
        frac st = max(lower[p].st, upper[q].st);
        frac ed = min(lower[p].ed, upper[q].ed);
        assert(st <= ed);
        if (lower[p].m == upper[q].m) {
            if (lower[p].b <= upper[q].b) {
                cout << "possible\n";
                exit(0);
            }
        } else if (lower[p].m < upper[q].m) {
            frac inter = intersect(lower[p], upper[q]);
            if (inter <= ed) {
                cout << "possible\n";
                exit(0);
            }
        } else {
            frac inter = intersect(lower[p], upper[q]);
            if (inter >= st) {
                cout << "possible\n";
                exit(0);
            }
        }
        if (lower[p].ed < upper[q].ed) p++;
        else q++;
    }
}
```

## 문제 1 (진화 2)

### 만점 풀이

우리가 알고 있는 것은 임의의 path에 대해서 원소들이 이미 정렬되어 있다는 사실이다. 따라서 트리의 leaf가 여러 개라면, 그 리프들로 가는 경로들을 merge sort 하듯이 merge하면 된다. 이것을 일반적으로 확장하면:

- 순서를 완전히 결정한 노드들의 순서열을 $S$라고 하자. 처음 $S = (0)$이다.
- 다음을 반복한다:
    + 리프까지 이어지는 경로를 하나 잡는다. 그 경로를 $P$라고 하면 $P$의 값들은 이미 정렬되어 있다.
    + 귀납가정 자체가 $S$가 이미 정렬되어 있다는 것이므로 둘을 merge sort 하듯이 합쳐서, 합쳐진 정렬된 순서열 $S$를 만든다.
    + 이때, $S$의 처음부터 볼 필요는 없다. 조상-자손 조건에 따라 $S$의 어떤 지점 이전에는 $P$의 원소가 등장하지 않음이 보장되기 때문이다.

이때, 항상 루트에서부터 시작하면 이미 순서열 $S$에 포함된 부분이 있을 수 있다. 따라서, 이미 $S$에 포함된 부분을 제외한 나머지 부분만 merge하면 된다. 그 부분이 연속된 경로임은 자명하다.

그렇다면 merge를 어떻게 적은 횟수의 비교로 할 수 있을까? $S$의 길이를 $L$, $P$의 길이를 $K$라 하고, $L \geq K$라 가정하자. 일반적인 merge 방법을 쓰면 $\mathcal{O}(L + K)$번의 비교가 필요하다. 그리고 실제 정렬에서 이 방법을 채택하는 이유는 시간복잡도가 가장 작기 때문이다. 하지만, 이 문제에서는 비교 횟수를 최소화하는 것이 목적이므로, inserting의 cost가 0이고, 따라서 이분탐색을 활용하는 것이 더 좋다. 이때 $P$의 원소를 앞에서부터 하나씩 하는 것은 비효율적인데, 만약에 $P$가 들어갈 위치가 앞쪽에 몰려 있다면, 모든 비교에 $\mathcal{O}(\log L)$번의 비교가 필요하기 때문이다. 따라서, $P$를 반으로 나누어, 중간 원소를 $S$에 이분탐색으로 넣고, 그 뒤로는 왼쪽 부분과 오른쪽 부분을 재귀적으로 merge하면 된다. 이때, 왼쪽 부분은 $S$의 왼쪽 부분과 merge하고, 오른쪽 부분은 $S$의 오른쪽 부분과 merge해야 한다. 가운데가 제일 좋은 이유는 구간의 길이가 불균등하게 나누어졌을 때, 최악의 경우 더 긴 구간에 더 많은 원소가 가는 것을 막기 위함이다. 양쪽에 삽입해야 할 원소가 반반씩 들어가는 것이 나누어지는 구간의 길이를 모르는 상황에서 최적이다.

이제 시간복잡도를 증명하자. 주어진 $L, K$에 대해 필요한 시간을 $T(L, K)$라 쓰면

$$T(L, K) = T\left(L_1, \frac{K}{2}\right) + T\left(L_2, \frac{K}{2}\right) + \log L \leq 2T\left(\frac{L}{2}, \frac{K}{2}\right) + \log L$$

가 성립하고, 초깃값 $T(L, 1) = \log L$이다. 따라서 $L/K$가 일정하니까 $f(K) = T(cK, K)$라 하면

$$f(K) \leq 2f\left(\frac{K}{2}\right) + \log K + \log (L/K)$$

이고 마스터 정리에 의해

$$T(L, K) = f(K) = \mathcal{O}(K ( 1 + \log (L/K)))$$

가 된다. 따라서, $\mathcal{O}(L + K)$와 비교해서 맞는 정렬 방법을 고르면 된다. 만점 풀이에서는 $L \leq 2K$이면 일반적인 merge를, $L > 2K$이면 위의 방법을 사용했다.

마지막으로 이 알고리즘이 문제에서 요구하는 조건을 만족시키는지 살피겠다. 길이 $L$의 순서열 $S$와 길이 $K$의 경로 $P$를 merge할 때 가능한 경우는 $\binom{L + K}{K}$개 존재한다. 그리고 스털링 근사에 의해 이 값의 로그는

$$\log \binom{L + K}{K} = (L+K) \log (L+K) - L \log L - K \log K = L \log \left( \frac{L+K}{L} \right) + K \log \left( \frac{L+K}{K} \right) $$

이다. 여기서 $L/K = x$라 두면, $\log (1 + 1/x) \leq 1/x$에서

$$\begin{align*} L \log (1 + 1/x) + K \log (1 + x) &= K \log x + L \log (1 + 1/x) + K \log (1 + 1/x) \\ &\leq K \log x + (L + K) \frac{1}{x} = K \log \left(\frac{L}{K}\right) + K + \frac{K^2}{L} \end{align*}$$

이므로, asymptotic하게 $\mathcal{O}(K ( 1 + \log (L/K)))$번의 비교로 merge하는 것이 충분한 성능이라는 것을 알 수 있다.

마지막으로, 구현 테크닉 측면에서는 $L > K$를 항상 보장하기 위해 깊이가 가장 깊은 리프부터 시작한다. 어차피 $S = (0)$인 제일 처음에는 비교하지 않을 것이므로 문제되지 않고, 그 이후에는 항상 저 조건이 만족됨을 쉽게 확인할 수 있다.

```cpp
#include <bits/stdc++.h>
#include "evolution2.h"
using namespace std;

vector<int> adj[10101];
vector<int> child[10101];
int par[10101];
int depth[10101];
vector<int> leaves;

void DFS(int u, int p = -1) {
    par[u] = p;
    depth[u] = (p == -1) ? 0 : depth[p] + 1;
    for (int v : adj[u]) {
        if (v == p) continue;
        child[u].push_back(v);
        DFS(v, u);
    }
    if (child[u].empty()) {
        leaves.push_back(u);
    }
}

int ch[10101];
void my_insert(vector<int>& order, vector<int> path, int l, int r) {
    if (path.empty()) return;

    if (r - l <= 2 * path.size()) {
        int i = 0;
        int j = l;
        int end = r;

        while (i < path.size()) {
            int pos = j;

            while (pos < end && compare(order[pos], path[i])) {
                ++pos;
            }

            order.insert(order.begin() + pos, path[i]);

            ++i;
            j = pos + 1;
            ++end;
        }
        return;
    }

    int idx = path.size() / 2;
    int v = path[idx];
    int s = l, e = r;
    while (s < e) {
        int m = (s + e) / 2;
        compare(order[m], v) ? s = m + 1: e = m;
    }
    order.insert(order.begin() + s, v);
    my_insert(order, vector<int>(path.begin(), path.begin() + idx), l, s);
    my_insert(order, vector<int>(path.begin() + idx + 1, path.end()), s + idx + 1, r + idx + 1);
}

vector<int> recover(int N, vector<int> U, vector<int> V) {
    vector<int> res(N);
    int r = 0;

    for (int i = 0; i < N; i++) {
        adj[i].clear();
        child[i].clear();
        ch[i] = 0;
        par[i] = -1;
        depth[i] = 0;
    }
    leaves.clear();

    for (int i = 0; i < N-1; i++) {
        adj[U[i]].push_back(V[i]);
        adj[V[i]].push_back(U[i]);
    }

    DFS(0);
    sort(leaves.begin(), leaves.end(), [](int a, int b) {
        return depth[a] > depth[b];
    });
    
    vector<int> order;
    order.push_back(0);
    ch[0] = 1;
    while (order.size() < N) {
        int v = leaves[0];
        leaves.erase(leaves.begin());

        vector<int> path;
        while (ch[v] == 0) {
            ch[v] = 1;
            path.push_back(v);
            v = par[v];
        }
        reverse(path.begin(), path.end());
        int s, e = order.size();
        for (int i = 0; i < order.size(); i++) {
            if (order[i] == v) {
                s = i + 1;
                break;
            }
        }
        my_insert(order, path, s, e);
    }

    for (int i = 0; i < N; i++) {
        res[order[i]] = i;
    }
    return res;
}
```

## 문제 3 (넘버링)

### 그래프가 트리인 경우

어떤 정점 $v$에 연결된 간선이 세 개라고 해보자. 이때 이미 한 쪽 방향의 서브트리에서 $v$ 방향으로 가는 경로 중에 수가 strictly increase하는 경로가 존재하고, 다른 방향의 서브트리에서 $v$ 방향으로 가는 경로 중에 수가 strictly decrease하는 경로가 존재한다면, 남은 쪽은 무조건 $v$와 같은 값을 가져야 한다.

그 이유는 아래 도식에서,

```
(a) ... -> 0 -> 1 -> ... -> v
(b) ... -> 2 -> 1 -> ... -> v <- 1 <- 1 <- ... <- 1 (c)
```

- (a)에서 (c)로 가는 경로는 단조증가해야 하므로 (c) 쪽의 값은 무조건 1 이상이다.
- (b)에서 (c)로 가는 경로는 단조감소해야 하므로 (c) 쪽의 값은 무조건 1 이하이다.
- 따라서 (c) 쪽의 값은 무조건 1이 된다.

또한, 어떤 정점 $v$에 대해 한 쪽 방향에 서브트리에서 $v$ 방향으로 가는 경로 중에 수가 strictly increase하는 경로가 존재하고, 다른 쪽 방향의 서브트리에서 $v$ 방향으로 가는 경로 중에 수가 strictly increase하는 경로가 모두 존재할 수도 있다:

```
1(v) <- 1(u) <- 2
             <- 0
```

하지만 $u$ 방향으로 이동하다 보면 위에서 본 것처럼 strictly increase하는 경로와 strictly decrease하는 경로가 두 개의 자식에서 존재하는 정점에 도달하게 될 것이다.

이상의 결과를 종합하면, 우리는 최적해가

- 경로 $v_1 \to v_2 \to ... \to v_k$에 대해, $v_1$, $v_2$, ..., $v_k$가 모두 다른 값을 가지고,
- $v_i$와 연결된 부분 ($v_i$를 루트로 하는 서브트리)는 $v_i$와 같은 값을 가진다

의 꼴이라는 것을 알 수 있다.

이제 tree dp로 이 문제를 해결해보자. 먼저, $dp[v]$는 $v$가 경로의 끝점일 때 가능한 최대 diversity 로 정의하자. 그러면

$$dp[v] = \max_{u \in child(v)} dp[u] + sz[u] \cdot (sz[v] - sz[u])$$

이다. 여기서 $sz[v]$는 $v$를 루트로 하는 서브트리의 크기이다.

답은,

- $v_1$과 $v_k$가 조상-자손 관계인 경우: 각 정점 $v$에 대해 $dp[v]$들을 고려해야 한다
- $v_1$과 $v_k$가 조상-자손 관계가 아닌 경우: 각 정점 $v$들에 대해

    $$\max_{u, w \in child(v)} dp[u] + dp[w] + sz[u] \cdot (N - sz[u]) + sz[w] \cdot (N - sz[w]) - sz[u] \cdot sz[w]$$

    들을 고려해야 한다.

두 번째 경우에는 최적화가 필요하다. 고정된 $u$에 대해 생각해보면, 우리가 구하는 값은

$$dp[u] + sz[u] \cdot (N - sz[u]) + \max_{w \in child(v)} dp[w] + sz[w] \cdot (N - sz[w]) - sz[u] \cdot sz[w]$$

이다. 따라서 $w$로부터 만든 직선 $y = - sz[w] \cdot x + dp[w] + sz[w] \cdot (N - sz[w])$들의 upper envelope에 $x = sz[u]$를 대입하면 뒤쪽 항을 구할 수 있다.

convex hull trick을 쓸 때는 upper envelope를 구해야하고 기울기가 음수이므로, 기울기의 절댓값이 감소하는(완만해지는) 순서대로 직선을 추가해야 한다. 또한, $u \neq w$이므로 매 $u$마다 현재의 envelope에 $x = sz[u]$를 대입해 값을 구하고, 그 뒤에 자식 $u$에 대응하는 직선을 추가해야 한다.

시간복잡도는 $\mathcal{O}(N \log N)$이다.

### 그래프가 일반 그래프인 경우

사이클에 속하는 경우에는 경로가 존재하므로 항상 같은 값이어야 한다. 즉, 단절선을 제거한 트리에서 여전히 같은 컴포넌트에 있는 정점들은 같은 값을 가져야 한다. 따라서 단절선들을 제거한 뒤의 각 컴포넌트를 하나의 정점으로 압축한 뒤, 압축된 트리에서 위의 tree dp를 수행하면 된다. 이때 압축된 정점이 원래 정점 몇 개를 포함하는지에 따라 $sz[v]$를 정의해야 한다.

시간복잡도는 $\mathcal{O}(N \log N + M)$이다.

*Note: 아래 코드에서 `BlockCutTree`는 생성형 AI로 구현되었음.*

```cpp
#include <bits/stdc++.h>
using namespace std;

struct BlockCutTree {
    int N, M;

    vector<int> U, V;

    // 압축된 트리의 인접 리스트
    vector<vector<int>> adj;

    // 각 압축 노드에 포함된 원래 정점 개수
    vector<int> weight;

private:
    vector<vector<pair<int, int>>> g;
    vector<int> tin, low;
    vector<bool> isBridge;
    vector<int> comp;

    int timer;
    int componentCount;

    void findBridges(int v, int parentEdge) {
        tin[v] = low[v] = timer++;

        for (auto [to, eid] : g[v]) {
            if (eid == parentEdge)
                continue;

            if (tin[to] == -1) {
                findBridges(to, eid);

                low[v] = min(low[v], low[to]);

                // v - to가 단절선
                if (low[to] > tin[v])
                    isBridge[eid] = true;
            }
            else {
                low[v] = min(low[v], tin[to]);
            }
        }
    }

    void makeComponents(int v, int id) {
        comp[v] = id;

        for (auto [to, eid] : g[v]) {
            // 단절선은 끊고 탐색
            if (isBridge[eid])
                continue;

            if (comp[to] != -1)
                continue;

            makeComponents(to, id);
        }
    }

    void build() {
        // ----------------------------------------
        // 1. Bridge 찾기
        // ----------------------------------------

        tin.assign(N, -1);
        low.assign(N, 0);
        isBridge.assign(M, false);

        timer = 0;

        for (int v = 0; v < N; ++v) {
            if (tin[v] == -1)
                findBridges(v, -1);
        }

        // ----------------------------------------
        // 2. Bridge를 제거했을 때의 component 찾기
        // ----------------------------------------

        comp.assign(N, -1);
        componentCount = 0;

        for (int v = 0; v < N; ++v) {
            if (comp[v] == -1) {
                makeComponents(v, componentCount);
                ++componentCount;
            }
        }

        // ----------------------------------------
        // 3. 각 component의 크기
        // ----------------------------------------

        weight.assign(componentCount, 0);

        for (int v = 0; v < N; ++v) {
            ++weight[comp[v]];
        }

        // ----------------------------------------
        // 4. Bridge를 component 사이의 edge로 변환
        // ----------------------------------------

        adj.assign(componentCount, {});

        for (int i = 0; i < M; ++i) {
            if (!isBridge[i])
                continue;

            int a = comp[U[i]];
            int b = comp[V[i]];

            adj[a].push_back(b);
            adj[b].push_back(a);
        }
    }

public:
    BlockCutTree(
        int N,
        int M,
        const vector<int>& U,
        const vector<int>& V
    ) : N(N), M(M), U(U), V(V) {

        g.resize(N);

        for (int i = 0; i < M; ++i) {
            g[U[i]].push_back({V[i], i});
            g[V[i]].push_back({U[i], i});
        }

        build();
    }
};

vector<int> adj[1010101];
vector<int> child[1010101];
long long sz[1010101];
long long dp[1010101];
long long ans = 0;

long long _N;

void DFS(int u, vector<int>& node_sz, int p = -1) {
    sz[u] = node_sz[u];
    for (int v : adj[u]) {
        if (v == p) continue;
        DFS(v, node_sz, u);
        child[u].push_back(v);
        sz[u] += sz[v];
    }
}

void solve(int u) {
    for (int v : child[u]) {
        solve(v);
        dp[u] = max(dp[u], dp[v] + sz[v] * (sz[u] - sz[v]));
    }
    ans = max(ans, dp[u]);

    if (child[u].empty()) return;

    struct Frac {
        long long a, b;
        bool operator<(const Frac& rhs) const {
            return a * rhs.b < b * rhs.a;
        }
    };
    struct Line {
        Frac slope;
        long long y_intercept;
        Frac lt = {0, 1}, rt = {1'000'000, 1};
        long long eval(long long x) const {
            return slope.a * x + y_intercept * slope.b;
        }
    };
    vector<Line> lines;
    for (int v : child[u]) {
        lines.push_back({{-sz[v], 1}, dp[v] + sz[v] * (_N - sz[v])});
    }
    vector<Line> dq;
    dq.push_back(lines[0]);
    int p = 0;
    for (int i = 1; i < lines.size(); i++) {
        int v = child[u][i];
        while (p > 0) {
            if (dq[p].rt < Frac{sz[v], 1}) {
                p--;
            }
            else break;
        }
        ans = max(ans, dq[p].eval(sz[v]) + dp[v] + sz[v] * (_N - sz[v]));

        Line newLine = lines[i];
        while (!dq.empty()) {
            auto last = dq.back();
            Frac intersection = {last.y_intercept - newLine.y_intercept, newLine.slope.a - last.slope.a};
            if (intersection < last.lt) {
                dq.pop_back();
            } else {
                dq[dq.size() - 1].rt = intersection;
                newLine.lt = intersection;
                dq.push_back(newLine);
                if (intersection < Frac{v, 1}) p = dq.size() - 1;
                break;
            }
        }
    }
}

long long max_diversity(int N, int M, vector<int> U, vector<int> V) {
    _N = N;

    BlockCutTree bct(N, M, U, V);
    int newN = bct.adj.size();

    for (int i = 0; i < newN; i++) {
        adj[i] = bct.adj[i];
    }
    DFS(0, bct.weight);

    for (int i = 0; i < newN; i++) {
        sort(child[i].begin(), child[i].end(), [](int a, int b) {
            return sz[a] > sz[b];
        });
    }

    solve(0);
    return ans;
}
```

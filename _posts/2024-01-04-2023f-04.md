## 2023f-04-01

그리디하게 앞에서부터 처리하면서 두 문자가 같으면 무조건 매칭시키는 것이 최적이다.

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;
 
string s, t;
vector<int> idx[26][2];
int last[101010][2];
 
int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(0);
 
    cin >> s >> t;
 
    for (int i = 0; i < t.length(); i++) {
        idx[t[i] - 'a'][i % 2].push_back(i);
    }
 
    for (int i = 0; i < s.length(); i++) {
        int idx0 = lower_bound(idx[s[i] - 'a'][0].begin(), idx[s[i] - 'a'][0].end(),
                               i == 0 ? -1 : last[i - 1][1]) - idx[s[i] - 'a'][0].begin();
        if (idx0 == idx[s[i] - 'a'][0].size()) last[i][0] = 1e9;
        else last[i][0] = idx[s[i] - 'a'][0][idx0];
 
        int idx1 = lower_bound(idx[s[i] - 'a'][1].begin(), idx[s[i] - 'a'][1].end(),
                               i == 0 ? -1 : last[i - 1][0]) - idx[s[i] - 'a'][1].begin();
        if (idx1 == idx[s[i] - 'a'][1].size()) last[i][1] = 1e9;
        else last[i][1] = idx[s[i] - 'a'][1][idx1];
    }
 
    if ((s.length() - t.length()) % 2 == 0 && last[s.length() - 1][(s.length() - 1) % 2] < t.length()) cout << "YES\n";
    else cout << "NO\n";
 
    return 0;
}
```

## 2023f-04-02

각 행이 $A_i$이고 각 열이 $B_j$에 대응될 때 $(i, j)$에 $|A_i - B_j|$가 저장된 이차원 배열을 생각하자. 그러면 선공은 행을 하나 지우는 것으로, 후공은 열을 하나 지우는 것으로 볼 수 있다. 따라서 그러면 각 행에서 나타나는 수들에서 가장 작은 수들의 최댓값이 답이 된다.

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
typedef pair<int, int> pii;
typedef pair<ll, ll> pll;
 
int n, a[1010], b[1010];
int diff[1010][1010], ans = 0;
 
int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(0);
 
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 1; i <= n; i++) cin >> b[i];
 
    for (int i = 1; i <= n; i++) for (int j = 1; j <= n; j++) diff[i][j] = abs(a[i] - b[j]);
 
    for (int i = 1; i <= n; i++) {
        int val = 1e9;
        for (int j = 1; j <= n; j++) val = min(val, diff[i][j]);
        ans = max(ans, val);
    }
 
    cout << ans << "\n";
 
    return 0;
}
```

## 2023f-04-03

핵심 아이디어는 가능한 모든 경우를 전부 관리하다가 불가능한 경우를 제거하는 것이다. 가능한 모든 비트스트링의 목록을 Trie로 관리한다면

- $i$번째 벚꽃소녀는 $i-1$번까지의 비트스트링을 따라 Trie로 내려간 정점에서
    - 양방향 중 한 방향만이 남아 았다면 답을 안다고 대답한다.
    - 두 방향 모두 가능하다면 답을 모른다고 대답한다.
- 탈출한 벚꽃소녀의 번호 $j$에 대해
    - 모든 자식 노드의 $j$번 벚꽃소녀 위치에서 두 방향 모두 가능한 경우를 제거한다.
- 탈출하지 못한 벚꽃소녀의 번호 $j$에 대해
    - 모든 자식 노드의 $j$번 벚꽃소녀 위치에서 한 방향만 가능한 경우를 제거한다.

이렇게 되면 $O(2^n)$의 시간복잡도가 되므로 TLE를 받는다. 고로 모든 벚꽃소녀에게 폭탄의 개수 $k$를 알린다는 사실을 이용해 크기 $k \times (n-k)$의 격자에서 문제를 해결하자. 그러면 $(1, 1)$에서 $(k, n-k)$에 도달하는 최단경로가 각각의 비트스트링에 일대일대응된다. 또, 상태는 $O(n^2)$개 이므로 라운드마다 $O(n^2)$에 문제를 해결할 수 있다. 이제 이 격자에서 위 행동을 다시 보자.

- $i$번째 벚꽃소녀는 $i-1$번까지의 비트스트링을 따라 온 도착 격자 좌표에서
    - 좌측 이동과 하방 이동 중 하나만이 남아 있다면 답을 안다고 대답한다.
    - 두 방향 모두 가능하다면 답을 모른다고 대답한다.
- 탈출한 벚꽃소녀의 번호 $j$에 대해
    - $(1, 1)$과의 거리가 $j$인 점의 자식 노드가 둘 이상이라면 그 점은 지나는 경로는 제거한다.
- 탈출하지 못한 벚꽃소녀의 번호 $j$에 대해
    - $(1, 1)$과의 거리가 $j$인 점의 자식 노드가 하나라면 그 점을 지나는 경로는 제거한다.

이 과정의 처리에 있어 지나지 않는 점에 의해 갇힌 부분은 절대 지날 수 없으므로 점화관계를 통해 매번 찾아 처리해야 할 필요가 있다.

유의미한 라운드 수는 수학적 귀납법에 의해 $n$ 이하이므로 전체 문제를 $O(Tn^3)$에 해결할 수 있다.

```cpp
#include <bits/stdc++.h>
using namespace std;

int t;
int n, k = 0, arr[110], dp[110][110], pos[110][2], ans[110];

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(0);
    
    cin >> t;
    while (t--) {
        cin >> n;
        k = 0;
        for (int i = 1; i <= n; i++) {
            char c; cin >> c;
            arr[i] = c - 'A';
            pos[i][0] = k;
            pos[i][1] = i - k - 1;
            ans[i] = 0;
            k += arr[i];
        }
        for (int i = 0; i <= k+1; i++) {
            for (int j = 0; j <= n-k+1; j++) {
                if (i <= k && j <= n-k) dp[i][j] = 1;
                else dp[i][j] = 0;
            }
        }

        int temp = n;
        while (temp--) {
            for (int i = 1; i <= n; i++) {
                if (!(dp[pos[i][0]][pos[i][1]+1] == 1 && dp[pos[i][0]+1][pos[i][1]] == 1)) ans[i] = 1;
            }
            for (int i = 0; i <= k; i++) {
                for (int j = 0; j <= n-k; j++) {
                    if (i == k && j == n-k) continue;
                    if (ans[i+j+1] == 1) if (dp[i][j+1] == 1 && dp[i+1][j] == 1) dp[i][j] = 0;
                    if (ans[i+j+1] == 0) if (!(dp[i][j+1] == 1 && dp[i+1][j] == 1)) dp[i][j] = 0;
                }
            }
            for (int i = k; i >= 0; i--) {
                for (int j = n-k; j >= 0; j--) {
                    if (i == k && j == n-k) continue;
                    if (dp[i][j+1] == 0 && dp[i+1][j] == 0) dp[i][j] = 0;
                }
            }
        }

        for (int i = 1; i <= n; i++) cout << ans[i];
        cout << "\n";
    }
    
    return 0;
}
```

## 문제 L

각 칸의 좌표와 보고 있는 방향을 묶어서 하나의 상태로 정의하면 functional graph를 얻는다. 탈출 정점을 별도로 만든 후에 그래프의 간선 방향을 뒤집어서 탈출 정점에서부터 BFS를 수행하면 각 정점에서 탈출 정점까지의 최단 거리를 구할 수 있다.

## 문제 I

각 $1 \leq i \leq N$에 대해 $1$번째 스트링의 $i$번째 수부터 $K-1$번째 스트링의 $i$번째 수를 하나의 벡터 $v_i$에 담아서 모으자. 또, 각 $1 \leq i \leq N$에 대해 $2$번째 스트링의 $i$번째 수부터 $K$번째 스트링의 $i$번째 수를 하나의 벡터 $w_i$에 담아서 모으자. 그러면 각 순열 $P$에 대해, $w_{P_i}$가 $v_i$와 같아야 한다. 우리는 사전순으로 가장 작은 순열을 구해야 하므로, 벡터가 같은 $v$의 인덱스들과 $w$의 인덱스들을 각각 오름차순으로 정렬한 후, $v$의 인덱스들을 $w$의 인덱스들에 매칭시키면 된다. 개수가 다르면 불가능한 것이다.

## 문제 K

$(i, i)$ 칸이 비어 있는 $i$들을 $a_1, a_2, \ldots, a_k$라 놓자. 그러면 임의의 $a_i < a_j$에 대해, $(a_i, a_j)$와 $(a_j, a_i)$는 우상향하는 대각선으로 커버해야 하므로, $(a_i + a_j) / 2$가 정수이면서 이 위치의 칸이 비어 있지 않아야 한다. 이 필요충분조건을 생각하면, $k$가 크지 않고, 전체 경우를 완전탐색해도 경우의 수가 그렇게 많지 않다. 따라서 그냥 백트레킹으로 문제를 해결하면 된다. `.`의 코너케이스에 유의하라.

## 문제 G

매개변수 탐색을 하자. 고정된 상한 $x$에 대해, 우리는 각 정점으로부터 적어도 이 위치에는 식료품 매장이 있어야 하는 구간 범위를 얻을 수 있다. 이제, 이 문제는 점을 $K$개 찍어서 모든 구간에 하나 이상의 점이 포함될 수 있는지 판단하는 문제로 바뀌었다.

이 경우에 점은 구간의 시점에만 찍으면 충분하다. 왜냐하면, 어떤 최적해가 주어졌을 때 모든 점들을 가장 큰 구간의 시작점으로 밀어도 여전히 최적해이기 때문이다. 이제 이렇게 되면 각 정점의 시작점에 식료품 매장을 두었을 때 다음으로 고려해야 하는 정점의 번호를 나타내는 functional graph를 얻을 수 있다. 그러면 필요한 점의 개수의 최솟값은 functional graph에서 한 바퀴 이상(자기 자신으로 오지 않고 통과해도 된다) 돌기 위해 움직하는 최소 횟수다.

이 횟수는 DFS를 돌리며 여태까지 방문한 정점을 기록하면 구할 수 있다. 큐의 첫 번째 정점 이상의 위치를 다시 방문했다면 큐에 들어 있는 정점의 수가 큐의 첫 번째 정점에서 한 바퀴 이상 돌기 위해 움직이는 최소 횟수이다. 이제 큐의 앞 정점 하나를 빼고 이어나가면 된다. 이 과정을 모든 정점을 방문할 때까지 반복하면 답이 된다는 것을 증명할 수 있다.

모든 정점이 한쪽으로 편향되어 있는 경우의 엣지 케이스에 유의하라.

## 문제 E

일단, 두 개의 수가 1인데 0이 나오는 것을 `min`과 `<=` 연산으로 만들 수 없다. 이것은 일반적으로도 성립하므로 주어진 변수에 모두 1을 넣었을 때 0이 나오는 경우는 불가능하다. 따라서, 모든 변수에 1을 넣었을 때 1이 나오는지 확인하고, 만약 0이 나온다면 "NO"를 출력하면 된다.

이제, 모든 변수의 `min`을 $k$로 쓰자. 그러면, $k=1$이면 답이 1이고, $k=0$인 경우에는 `0` 리터럴을 사용할 수 있으므로:
- `(max A B)`를 `((A <= B) <= B)`로 바꾸고, (smaller to larger를 위해 더 적은 operation을 사용하는 쪽을 `B`로 둔다.)
- `(A < B)`를 `(min (A <= 0) B)`로 바꾸면 된다.

최종적으로는 $k$와 주어진 식의 `max`를 구하면 되므로, 위에 제시한 방법으로 `max`를 `<=`와 `min`으로 바꾸면 eqivalent한 식을 얻을 수 있다. 수학적 귀납법으로 처음 연산 수가 $N$일 때, 최종 연산 개수가 $N^2$ 이하임을 증명할 수 있으므로 문제가 해결되었다.

```cpp
#include <bits/stdc++.h>
using namespace std;

string s;
string ans;

vector<char> vars;

string zero() {
    string result = string(1, vars[0]);
    for (size_t i = 1; i < vars.size(); ++i) {
        result = "(min " + result + " " + string(1, vars[i]) + ")";
    }
    return result;
}

bool eval(size_t l, size_t r, size_t mask) {
    if (l == r) return (mask >> (s[l] - 'a')) & 1;

    l++; r--;

    if (string(s.begin() + l, s.begin() + l + 3) == "min") {
        int cnt = 0;
        for (size_t i = l + 4; i < r; ++i) {
            if (s[i] == '(') ++cnt;
            else if (s[i] == ')') --cnt;
            if (cnt == 0) {
                return eval(l + 4, i, mask) && eval(i + 2, r, mask);
            }
        }
    } else if (string(s.begin() + l, s.begin() + l + 3) == "max") {
        int cnt = 0;
        for (size_t i = l + 4; i < r; ++i) {
            if (s[i] == '(') ++cnt;
            else if (s[i] == ')') --cnt;
            if (cnt == 0) {
                return eval(l + 4, i, mask) || eval(i + 2, r, mask);
            }
        }
    } else {
        size_t mid = l;
        int cnt = 0;
        do {
            if (s[mid] == '(') ++cnt;
            else if (s[mid] == ')') --cnt;
            ++mid;
        } while (cnt != 0 || s[mid] != '<');
        if (s[mid + 1] == '=') {
            return eval(l, mid - 2, mask) <= eval(mid + 3, r, mask);
        } else {
            return eval(l, mid - 2, mask) < eval(mid + 2, r, mask);
        }
    }
}

pair<string, size_t> solve(size_t l, size_t r) { // [l, r]
    if (l == r) return {string(1, s[l]), l};
    
    l++; r--;

    if (string(s.begin() + l, s.begin() + l + 3) == "min") {
        int cnt = 0;
        for (size_t i = l + 4; i <= r; ++i) {
            if (s[i] == '(') ++cnt;
            else if (s[i] == ')') --cnt;
            if (cnt == 0) {
                auto [left, left_num] = solve(l + 4, i);
                auto [right, right_num] = solve(i + 2, r);
                return {
                    "(min " + left + " " + right + ")", 
                    left_num + right_num + 1
                };
            }
        }
    } else if (string(s.begin() + l, s.begin() + l + 3) == "max") {
        int cnt = 0;
        for (size_t i = l + 4; i <= r; ++i) {
            if (s[i] == '(') ++cnt;
            else if (s[i] == ')') --cnt;
            if (cnt == 0) {
                auto [left, left_num] = solve(l + 4, i);
                auto [right, right_num] = solve(i + 2, r);
                if (left_num < right_num) {
                    swap(left, right);
                    swap(left_num, right_num);
                }
                return {
                    "((" + left + " <= " + right + ") <= " + right + ")", 
                    left_num + right_num * 2 + 2
                };
            }
        }
    } else {
        size_t mid = l;
        int cnt = 0;
        do {
            if (s[mid] == '(') ++cnt;
            else if (s[mid] == ')') --cnt;
            ++mid;
        } while (cnt != 0 || s[mid] != '<');
        if (s[mid + 1] == '=') {
            auto [left, left_num] = solve(l, mid - 2);
            auto [right, right_num] = solve(mid + 3, r);
            return {
                "(" + left + " <= " + right + ")",
                left_num + right_num + 1
            };
        } else {
            auto [left, left_num] = solve(l, mid - 2);
            auto [right, right_num] = solve(mid + 2, r);
            return {
                "(min (" + left + " <= " + zero() + ") " + right + ")",
                left_num + right_num + vars.size() + 1
            };
        }
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    getline(cin, s);

    for (size_t i = 0; i < s.length(); ++i) {
        char c = s[i];
        if ('a' <= c && c <= 'j') {
            if (i == 0 || s[i - 1] != 'm') vars.push_back(c);
        }
    }
    sort(vars.begin(), vars.end());
    vars.erase(unique(vars.begin(), vars.end()), vars.end());

    if (eval(0, s.length() - 1, 1023) == false) {
        cout << "NO\n";
        return 0;
    }

    auto [result, num] = solve(0, s.length() - 1);

    cout << "YES\n";
    cout << "((" + result + " <= " + zero() + ") <= " + zero() + ")" << "\n";

    return 0;
}
```

## 문제 H

원끼리의 교점은 최대 2개이기 때문에, 원 $N$개의 교점으로 만들어지는 영역의 수는 최대 $N^2 - N + 2$개다. 곧, $N \geq 4$에서 4번 이후의 원들은 고려하지 않아도 된다. 어차피 원이 네 개가 있으면 영역 16개가 만들어지지 못하기 때문이다.

결국 우리는 $(x-a)^2 + (y-b)^2 < r^2$ 또는 $(x-a)^2 + (y-b)^2 > r^2$의 형태로 주어진 $N$개의 원의 조건을 만족하는 영역이 존재하는지 판단하는 함수만 짜면 문제를 해결할 수 있다. 잘려서 생긴 원의 호의 중점과 원의 경계 근처만 검사하면 충분하고, 아래는 LLM로 구현된 함수를 이용한 정답 풀이이다.

```cpp
#include <bits/stdc++.h>
using namespace std;


using ld = long double;

const ld PI = acosl(-1.0L);
const ld EPS = 1e-12L;

struct Circle {
    ld x, y, r;
    int type; // 0: < r^2, 1: > r^2
};

struct Point {
    ld x, y;
};

static ld norm2(ld x, ld y) {
    return x * x + y * y;
}

static bool satisfy(const vector<Circle>& c, const Point& p) {
    for (const auto& q : c) {
        ld d2 = norm2(p.x - q.x, p.y - q.y);
        ld v = d2 - q.r * q.r;

        if (q.type == 0) {
            if (!(v < 0)) return false;
        } else {
            if (!(v > 0)) return false;
        }
    }
    return true;
}

static void addAngle(vector<ld>& a, ld theta) {
    theta = fmodl(theta, 2 * PI);
    if (theta < 0) theta += 2 * PI;
    a.push_back(theta);
}

static bool testNearBoundary(
    const vector<Circle>& c,
    int idx,
    ld theta
) {
    const Circle& q = c[idx];

    Point p{
        q.x + q.r * cosl(theta),
        q.y + q.r * sinl(theta)
    };

    // Outward normal from the circle.
    ld nx = cosl(theta);
    ld ny = sinl(theta);

    // The constraint of this circle determines which side we need.
    ld dir = (q.type == 0 ? -1.0L : 1.0L);

    // Move a little to the required side. If another circle boundary
    // is very close, repeatedly reduce the step.
    ld scale = max<ld>(1.0L, q.r);
    ld step = scale;

    for (int it = 0; it < 120; ++it) {
        Point p2{
            p.x + dir * nx * step,
            p.y + dir * ny * step
        };

        if (satisfy(c, p2))
            return true;

        step *= 0.5L;
    }

    return false;
}

bool existsRegion(const vector<Circle>& input) {
    int n = (int)input.size();

    if (n == 0) return true;

    vector<Circle> c;
    c.reserve(n);

    // Remove exact duplicate constraints.
    for (const auto& q : input) {
        bool found = false;

        for (auto& p : c) {
            if (q.x == p.x && q.y == p.y && q.r == p.r) {
                if (q.type != p.type)
                    return false; // x < r and x > r simultaneously
                found = true;
                break;
            }
        }

        if (!found)
            c.push_back(q);
    }

    n = (int)c.size();

    // First try an arbitrary point. This also handles the case where
    // the feasible region is unbounded and has no relevant boundary.
    Point origin{0, 0};
    if (satisfy(c, origin))
        return true;

    // For every circle, examine every arc determined by its
    // intersections with the other circles.
    for (int i = 0; i < n; ++i) {
        vector<ld> ang;

        const auto& A = c[i];

        for (int j = 0; j < n; ++j) {
            if (i == j) continue;

            const auto& B = c[j];

            ld dx = B.x - A.x;
            ld dy = B.y - A.y;
            ld d2 = dx * dx + dy * dy;

            // Concentric circles.
            if (d2 <= EPS * EPS)
                continue;

            ld d = sqrtl(d2);

            // No intersection.
            if (d > A.r + B.r + EPS)
                continue;
            if (d < fabsl(A.r - B.r) - EPS)
                continue;

            ld base = atan2l(dy, dx);

            ld cosv =
                (A.r * A.r + d2 - B.r * B.r) /
                (2.0L * A.r * d);

            cosv = max<ld>(-1.0L, min<ld>(1.0L, cosv));

            ld delta = acosl(cosv);

            addAngle(ang, base + delta);
            addAngle(ang, base - delta);
        }

        sort(ang.begin(), ang.end());

        vector<ld> uniqueAng;
        for (ld x : ang) {
            if (uniqueAng.empty() ||
                fabsl(x - uniqueAng.back()) > 1e-11L) {
                uniqueAng.push_back(x);
            }
        }
        ang.swap(uniqueAng);

        // No intersections: the whole circle is one arc.
        if (ang.empty()) {
            if (testNearBoundary(c, i, 0))
                return true;
            continue;
        }

        int m = (int)ang.size();

        // Test the midpoint of every arc.
        for (int k = 0; k < m; ++k) {
            ld a = ang[k];
            ld b = (k + 1 < m ? ang[k + 1] : ang[0] + 2 * PI);

            if (b - a <= 1e-14L)
                continue;

            ld mid = (a + b) * 0.5L;

            if (testNearBoundary(c, i, mid))
                return true;
        }
    }

    return false;
}

void solve() {
    int N, X[220], Y[220], R[220];
    cin >> N;
    for (int i = 0; i < N; i++) {
        cin >> X[i] >> Y[i] >> R[i];
    }
    int M = min(N, 4);
    vector<Circle> conds(M);
    for (int i = 0; i < M; i++) {
        conds[i].x = X[i];
        conds[i].y = Y[i];
        conds[i].r = R[i];
    }
    for (int mask = 0; mask < (1 << M); mask++) {
        for (int i = 0; i < M; i++) {
            conds[i].type = (mask & (1 << i)) != 0;
        }
        if (!existsRegion(conds)) {
            cout << "NO" << endl;
            for (int i = 0; i < M; i++) {
                cout << (conds[i].type ? "0" : "1") << " ";
            }
            for (int i = M; i < N; i++) {
                cout << "0" << " ";
            }
            return;
        }
    }
    cout << "YES" << endl;
}


int main() {
    int T;
    cin >> T;
    while (T--) {
        solve();
    }
}
```

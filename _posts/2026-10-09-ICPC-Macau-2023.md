## 문제 D

문제의 maximum degree 조건에 따라 그래프의 구조가 제한된다. 그래프의 노드 개수가 $n$이면 최대 간선 수는 $\frac{3n}{2}$이고 이 값이 $2n-2$ 이상이어야 하므로 $n \leq 4$이다.

- $n=1$이면 간선이 없으므로 항상 YES이다.
- $n=2$이면 두 정점 사이를 연결하는 파랑 간선과 빨강 간선 모두가 존재해야 한다.
- $n=3$이면 최대 간선 개수가 4이고 필요한 간선 개수도 4이므로 선형 트리 두 개가 겹치는 경우만 가능하다.
- $n=4$이면 최대 간선 개수가 6이고 필요한 간선 개수도 6이므로 선형 트리 두 개가 겹치는 경우만 가능하다.

시간복잡도는 $O(n+m)$이다.

## 문제 H

문제의 조건을 해석하면 각 정점 $v$에 대해 $v$의 서브트리에 속하는 숫자의 개수가 $v$의 서브트리의 크기 이상인 순열의 개수를 찾는 것이다. 따라서, $dp[v][\alpha]$를 $v$를 루트로하는 서브트리에서 $\alpha$개만큼 더 많은 개수의 숫자를 선택하는 경우의 수라고 정의하자. 그러면, $v$의 선택 횟수 $\alpha_0$와 $v$의 각 자식 $u_i$의 선택 횟수 $\alpha_i$에 대해, 

$$dp[v][\alpha] = \sum_{\alpha_0 + \sum_i \alpha_i = \alpha + 1} \frac{(sz[v] + \alpha)!}{\alpha_0! (sz[u_i]+\alpha_1)! \cdots (sz[u_k]+\alpha_k)!} \prod_i dp[u_i][\alpha_i]$$

여기서 $sz[v]$는 $v$를 루트로하는 서브트리의 크기이다.

이것은 자식을 하나씩 추가하면서 그 정점의 dp 테이블을 업데이트하는 dp 테크닉으로 $O(nh^2)$에 해결할 수 있다. 여기서 $h$는 트리의 높이이다. 문제의 랜덤 데이터 생성 조건에 따라 $h = O(\log n)$이므로 시간 복잡도는 $O(n \log^2 n)$이다.

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, sz[101010];
vector<int> child[101010];

long long MOD = 998'244'353;
long long fact[101010], invfact[101010];
vector<long long> dp[101010];

long long mypow(long long a, long long b) {
    long long res = 1;
    while (b) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

void solve(int v, int a) {
    sz[v] = 0;
    dp[v].resize(a+2, 1);
    for (int u : child[v]) {
        solve(u, a+1);

        vector<long long> temp(a+2, 0);
        for (int i = 0; i <= a+1; i++) {
            for (int j = 0; i+j <= a+1; j++) {
                temp[i+j] = (temp[i+j] + (
                    dp[u][j] * dp[v][i] % MOD
                             * fact[sz[v] + sz[u] + i + j] % MOD 
                             * invfact[sz[v] + i] % MOD 
                             * invfact[sz[u] + j] % MOD
                )) % MOD;
            }
        }

        sz[v] += sz[u];
        dp[v] = temp;
    }
    sz[v]++;
    dp[v].erase(dp[v].begin());
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;

    for (int i = 2; i <= n; i++) {
        int p;
        cin >> p;
        child[p].push_back(i);
    }

    for (int i = 0; i <= n; i++) {
        fact[i] = (i == 0 ? 1 : fact[i-1] * i % MOD);
        invfact[i] = mypow(fact[i], MOD-2);
    }

    solve(1, 0);
    cout << dp[1][0] << endl;

    return 0;
}
```

## 문제 E

사전순으로 가장 앞선 위상정렬 순서로부터는, 큰 수가 앞에 왔다면 둘 사이에 제약이 있다는 것을 의미한다. 따라서, 각 $a_i$의 앞에서 가장 뒤쪽에 있는 그것보다 큰 수 $a_j$를 찾아서, $a_j \rightarrow a_i$라는 간선을 추가하면 된다. 유사하게, 사전순으로 가장 늦은 위상정렬 순서에서는 작은 수가 뒤에 왔다면 둘 사이에 제약이 있다는 것을 의미한다. 따라서, 각 $a_i$의 뒤에서 가장 앞쪽에 있는 그것보다 작은 수 $a_j$를 찾아서, $a_i \rightarrow a_j$라는 간선을 추가하면 된다.

이렇게 만들어진 그래프는 최소 간선 그래프이고, 이 그래프의 실제 결과가 주어진 위상정렬 순서와 다르면 불가능하다는 것을 증명할 수 있다. 시간복잡도는 $O(n)$이다.

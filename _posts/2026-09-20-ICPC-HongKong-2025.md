## 문제 H

문제 조건에 따르면 답은 $n-2$ 이상이다. 그리고 답이 $n-1$이 된다면 $i$번째를 제거한 문자열과 $j$번째를 제거한 문자열이 같은 $i \neq j$가 존재한다는 뜻인데, 이것은 $i$번째부터 $j$번째까지의 문자가 모두 같다는 것과 동치이다. 따라서 연속된 같은 문자열이 있으면 답이 $n-1$이 되고, 그렇지 않으면 답은 $n-2$가 된다.

## 문제 J

그리디 알고리즘으로 해결할 수 있다. 일반성을 잃지 않고 $l_1 \leq l_2 \leq l_3$라 하자. 그러면 $N$문제를 모두 풀려면 1번 사람이 모든 문제를 푸는데 걸리는 시간이 $l_1$ 이하이고, 1번 및 2번 사람이 모든 문제를 푸는데 걸리는 시간이 $l_2$ 이하이며, 1번, 2번, 3번 사람이 모든 문제를 푸는데 걸리는 시간이 $l_3$ 이하여야 한다.

이걸 만족하고 나면, 우리는 가장 시간이 적게 걸리는 문제부터 푸는 것이 최소 패널티라는 것을 알 수 있다. 그런데, 1번 사람이 $l_1$ 전에는 모든 문제를 풀고 가야 하고, 2번 사람이 $l_2$ 전에는 모든 문제를 풀고 가야 하기 때문에 2번 사람과 3번 사람이 각각 개입할 수 있는 추가 시간이 제한되어 있다. 따라서, 개입할 수 있는 사람에 한정하여 가장 시간이 적게 걸리는 문제부터 풀어야 한다. 이를 반복하면 된다.

## 문제 K

stack을 사용해 매 위치 $i$에서 $i$가 커지는 방향으로 돌면서 $i$번째 수보다 큰 수가 등장하는 가장 앞선 인덱스를 기록한다. 그러면 다음의 반복으로 답을 구할 수 있다:
1. 길이 $l$의 maximum prefix sequence를 고려했을 때 사전순으로 가장 앞선 위치들 $a_1, \ldots$가 있다고 하자.
2. $a_i + l$번째 위치에서 $a_i + l$번째 수보다 큰 수가 등장하는 가장 앞선 순간을 $b_i$라고 하자.
3. $a_i + l$번째 수가 가장 작고, $b_i$와 $a_i + l$ 사이의 거리가 가장 먼 $a_i$들만 여전히 optimal이다.
4. $l$은 최적 $a_i$에서 $b_i$와 $a_i$ 사이의 거리로 바꾸면 된다.
위 과정을 $l$이 $n$이 되거나, $a_i$가 하나만 남을 때까지 반복하면 된다.

전부 같은 경우를 제외하면, 각 $l$에서 $a$들의 개수는 최대 $N/l$개이므로 시간 복잡도는 $O(N \log N)$이다.

## 문제 B

트리 dp를 하자. 트리 dp를 할 때, 자식 노드를 하나씩 차례대로 합칠 수 있도록 dp를 구상해야 시간 내에 통과할 수 있다. 따라서, $dp[v][k][c]$를 $v$를 루트로 하는 서브트리에서 현재 살펴본 자식들만 고려했을 때, $k$개의 연속된 간선을 제거하여서 얻을 수 있는 최소 비용으로 하고, $c$는 이 경로가 부모와 연결될 수 있는지를 판단하기 위해 $v$에서 그 자식으로 가는 단방향 경로의 개수로 지정하자. 문제 조건에 따라 $c$는 0, 1, 2 중 하나이다.

그러면, 자식 노드 $u$를 합칠 때, $v-u$ 중에 몇 번 쿠폰을 사용할지 고려하면 된다:
1. 쿠폰을 사용하지 않는 경우: 각 $c$에서 $dp[v][i+j][c] \leftarrow dp[v][i][c] + dp[u][j][0] + 2w$로 갱신한다. 단, **$j$는 무조건 0이어야 한다.**
2. 쿠폰을 한 번 사용하는 경우: $dp[v][i+j+1][c+1] \leftarrow dp[v][i][c] + dp[u][j][0] + w$ 또는 $dp[v][i+j+1][c+1] \leftarrow dp[v][i][c] + dp[u][j][1] + w$로 갱신한다.
3. 쿠폰을 두 번 사용하는 경우: $dp[v][i+j+2][c] \leftarrow dp[v][i][c] + dp[u][j][0]$로 갱신한다. 단, **$j$는 무조건 $2 \cdot sz[u] - 2$이어야 한다.**

매번 합칠 때마다 새로운 dp를 만들어 토글링하면 된다. 답은, 각 $v$에서 $v$ 위쪽에는 쿠폰을 사용하지 않는다고 보고 정답 배열을 업데이트하면 된다. 시간복잡도는 $O(N^2)$이다.

```cpp
#include <bits/stdc++.h>
using namespace std;

int t, n;
vector<pair<int, long long>> adj[2020];
int sz[2020];
long long wtot = 0, wsum[2020], ans[4040], dp[2020][4040][3], dp2[2020][4040][3];

void solve(int v, int par = 0) {
    sz[v] = 1;
    wsum[v] = 0;
    dp[v][0][0] = dp[v][0][1] = dp[v][0][2] = 0;

    for (auto [u, w] : adj[v]) {
        if (u == par) continue;
        solve(u, v);

        wsum[v] += wsum[u] + w * 2;

        for (int i = 0; i <= 2 * sz[v] + 2 * sz[u] - 2; i++) {
            dp2[v][i][0] = dp2[v][i][1] = dp2[v][i][2] = 1e18;
        }
        
        // zero added
        for (int i = 0; i <= 2 * sz[v] - 2; i++) {
            int j = 0;
            dp2[v][i + j][0] = min(dp2[v][i + j][0], dp[v][i][0] + dp[u][j][0] + w * 2);
            dp2[v][i + j][1] = min(dp2[v][i + j][1], dp[v][i][1] + dp[u][j][0] + w * 2);
            dp2[v][i + j][2] = min(dp2[v][i + j][2], dp[v][i][2] + dp[u][j][0] + w * 2);
        }

        // one added
        for (int i = 0; i <= 2 * sz[v] - 2; i++) {
            for (int j = 0; j <= 2 * sz[u] - 2; j++) {
                dp2[v][i + j + 1][1] = min(dp2[v][i + j + 1][1], dp[v][i][0] + dp[u][j][0] + w);
                dp2[v][i + j + 1][1] = min(dp2[v][i + j + 1][1], dp[v][i][0] + dp[u][j][1] + w);
                dp2[v][i + j + 1][2] = min(dp2[v][i + j + 1][2], dp[v][i][1] + dp[u][j][0] + w);
                dp2[v][i + j + 1][2] = min(dp2[v][i + j + 1][2], dp[v][i][1] + dp[u][j][1] + w);
            }
        }

        // two added
        for (int i = 0; i <= 2 * sz[v] - 2; i++) {
            int j = 2 * sz[u] - 2;
            dp2[v][i + j + 2][0] = min(dp2[v][i + j + 2][0], dp[v][i][0] + dp[u][j][0]);
            dp2[v][i + j + 2][1] = min(dp2[v][i + j + 2][1], dp[v][i][1] + dp[u][j][0]);
            dp2[v][i + j + 2][2] = min(dp2[v][i + j + 2][2], dp[v][i][2] + dp[u][j][0]);
        }

        sz[v] += sz[u];

        for (int i = 0; i <= 2 * sz[v] - 2; i++) {
            dp[v][i][0] = dp2[v][i][0];
            dp[v][i][1] = dp2[v][i][1];
            dp[v][i][2] = dp2[v][i][2];
        }
    }
    
    for (int i = 0; i <= 2 * sz[v] - 2; i++) {
        ans[i] = min(ans[i], dp[v][i][0] + wtot - wsum[v]);
        ans[i] = min(ans[i], dp[v][i][1] + wtot - wsum[v]);
        ans[i] = min(ans[i], dp[v][i][2] + wtot - wsum[v]);
    }
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(0);

    cin >> t;

    while (t--) {
        cin >> n;
        for (int i = 1; i <= n; i++) {
            adj[i].clear();
        }

        for (int i = 0; i <= 2 * n - 2; i++) {
            ans[i] = 1e18;
        }

        wtot = 0;
        for (int i = 1; i < n; i++) {
            int u, v;
            long long w;
            cin >> u >> v >> w;
            adj[u].push_back({v, w});
            adj[v].push_back({u, w});
            wtot += 2 * w;
        }

        solve(1);

        for (int i = 0; i <= 2 * n - 2; i++) {
            cout << ans[i] << " ";
        }
        cout << endl;
    }
}
```

## 문제 I

루트 $r$에 대해, DFS 순서 상의 그 다음 원소 $v$의 서브트리의 구간을 생각하자. 이 구간을 인덱스 기준으로 $[l, r]$로 쓰겠다. $[l, r]$이 가능할 필요충분조건은, $[l, r]$에 속한 모든 원소가 각 행에서 연속한 구간을 이루고, 첫 번째 원소는 모든 행에서 같은 원소여야 한다.

따라서, $dp[l][r]$을 $l$번째부터 $r$번째까지의 원소를 포함하는 구간의 원소들을 모두 포함하는 서브트리의 개수라고 정의하면, $dp[l][r] = \sum_{t=l}^{r} dp[l+1][t] \cdot dp[t+1][r]$가 된다. 단, $[l, t]$가 유효한 구간이어야 한다.

여기서 유효한 구간을 $O(1)$에 판단해야해야 시간 내에 싫행된다. 따라서, $O(N^2M)$에 유효한 구간을 전처리하자. 시간복잡도는 $O(N^2M)$이다.

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m, arr[550][550], pos[550][550];

bool is_valid[550][550];

long long MOD = 1'000'000'007;
long long dp[550][550];

void solve(int l, int r) {
    if (l > r) {
        dp[l][r] = 1;
        return;
    }

    if (dp[l][r] != -1) {
        return;
    }

    dp[l][r] = 0;

    for (int t = l; t <= r; t++) {
        int v = arr[1][t];

        if (!is_valid[l][t]) continue;

        solve(l + 1, t);
        solve(t + 1, r);
        dp[l][r] = (dp[l][r] + dp[l + 1][t] * dp[t + 1][r]) % MOD;
    }

    // cout << "dp[" << l << "][" << r << "] = " << dp[l][r] << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n >> m;

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            int x;
            cin >> x;
            arr[i][j] = x;
            pos[i][x] = j;
        }
    }

    for (int l = 1; l <= n; l++) {
        vector<int> lt(m+1), rt(m+1);
        for (int r = l; r <= n; r++) {
            int v = arr[1][r];
            bool valid = true;

            if (r == l) {
                for (int i = 1; i <= m; i++) {
                    lt[i] = pos[i][v];
                    rt[i] = pos[i][v];
                }
            } else {
                for (int i = 1; i <= m; i++) {
                    lt[i] = min(lt[i], pos[i][v]);
                    rt[i] = max(rt[i], pos[i][v]);
                    if (rt[i] - lt[i] + 1 != r - l + 1) {
                        valid = false;
                    }
                    if (arr[i][lt[i]] != arr[1][lt[1]]) {
                        valid = false;
                    }
                }
            }
            
            is_valid[l][r] = valid;
        }
    }

    for (int i = 1; i <= n; i++) {
        for (int j = i; j <= n; j++) dp[i][j] = -1;
    }

    solve(2, n);

    cout << dp[2][n] << "\n";
    
    return 0;
}
```

## 문제 F

### Step 1

사이클에만 방향을 주고, 나머지 간선들은 사이클에서는 무조건 나가면서 또 다른 사이클을 만들지 못하도록 방향을 주면 된다. 이것은, 사이클에 작은 번호를 매핑해두고, 나머지 정점들에 큰 번호를 임의로 매핑한 뒤, 번호가 작은 곳에서 큰 곳으로 향하도록 간선의 방향을 지정하면 쉽게 할 수 있다.

### Step 2

이제 사이클을 찾자. 먼저 SCC를 시행하면 유일하게 3 이상의 크기를 갖는 SCC에 우리가 원하는 사이클이 있다. 여기서, 사이클 내부의 간선이 제일 큰 사이클을 찾는 것을 방해한다!. 하지만, 사이클 내부의 간선도 번호에 따라 매핑하여 반대 방향 사이클이 없도록 방향을 지정하면, 적어도 하나 이상의 정점은 무조건 outdegree가 1이고 사이클의 일부분을 확정할 수 있다. 이 간선을 $u \rightarrow v$라 한다면, $v$로 들어가는 모든 간선은 최대 크기 사이클과 무관하므로, $v$로 들어오는 간선들을 모두 제거하고 다시 outdegree가 1인 정점을 찾아서 반복하면, 결국 최대 크기 사이클을 찾을 수 있다.

위상정렬 하듯이 큐로 구현하면 시간복잡도는 $O(N + M)$이다.

***참고: 코드는 AI로 생성되었음.***

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m;

void step1(void) {
    cin >> n >> m;
    vector<pair<int, int>> edges(m);
    for (auto &[u, v] : edges) {
        cin >> u >> v;
    }

    int k;
    vector<int> cycle;
    vector<int> num(n + 1);
    vector<int> cycle_pos(n + 1, -1);

    for (int i = 1; i <= n; i++) num[i] = n + i;

    cin >> k;
    cycle.reserve(k);
    for (int i = 0; i < k; i++) {
        int x;
        cin >> x;
        cycle.push_back(x);
        num[x] = i + 1;
        cycle_pos[x] = i;
    }

    for (int i = 0; i < k; i++) {
        int u = cycle[i], v = cycle[(i + 1) % k];
        cout << u << " " << v << "\n";
    }

    // Except for the closing edge p_k -> p_1 printed above, orient every
    // remaining edge from the earlier vertex to the later vertex in `num`.
    for (auto [u, v] : edges) {
        int pu = cycle_pos[u], pv = cycle_pos[v];
        bool is_cycle_edge = pu != -1 && pv != -1 &&
            ((pu + 1) % k == pv || (pv + 1) % k == pu);
        if (is_cycle_edge) continue;

        if (num[u] < num[v]) {
            cout << u << " " << v << "\n";
        } else {
            cout << v << " " << u << "\n";
        }
    }
}

struct Edge {
    int from, to;
};

void step2(void) {
    cin >> n >> m;

    vector<Edge> edges(m);
    vector<vector<int>> out_edges(n + 1), in_edges(n + 1);
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        edges[i] = {u, v};
        out_edges[u].push_back(i);
        in_edges[v].push_back(i);
    }

    // Iterative Kosaraju: recursion can overflow when n is close to 5e5.
    vector<char> visited(n + 1, false);
    vector<int> next_edge(n + 1, 0), order;
    vector<int> dfs_stack;
    order.reserve(n);
    dfs_stack.reserve(n);

    for (int start = 1; start <= n; start++) {
        if (visited[start]) continue;

        dfs_stack.clear();
        dfs_stack.push_back(start);
        visited[start] = true;

        while (!dfs_stack.empty()) {
            int u = dfs_stack.back();
            if (next_edge[u] < (int)out_edges[u].size()) {
                int edge_id = out_edges[u][next_edge[u]++];
                int v = edges[edge_id].to;
                if (!visited[v]) {
                    visited[v] = true;
                    dfs_stack.push_back(v);
                }
            } else {
                order.push_back(u);
                dfs_stack.pop_back();
            }
        }
    }

    fill(visited.begin(), visited.end(), false);
    vector<int> cycle_scc;
    vector<int> current_scc;

    for (int i = n - 1; i >= 0; i--) {
        int start = order[i];
        if (visited[start]) continue;

        current_scc.clear();
        dfs_stack.clear();
        dfs_stack.push_back(start);
        visited[start] = true;

        while (!dfs_stack.empty()) {
            int u = dfs_stack.back();
            dfs_stack.pop_back();
            current_scc.push_back(u);

            for (int edge_id : in_edges[u]) {
                int v = edges[edge_id].from;
                if (!visited[v]) {
                    visited[v] = true;
                    dfs_stack.push_back(v);
                }
            }
        }

        if (current_scc.size() >= 3) {
            cycle_scc = std::move(current_scc);
            break;
        }
    }

    if (cycle_scc.empty()) return;

    vector<char> in_cycle_scc(n + 1, false);
    for (int u : cycle_scc) in_cycle_scc[u] = true;

    vector<char> active(m, false);
    vector<int> out_degree(n + 1, 0);
    for (int edge_id = 0; edge_id < m; edge_id++) {
        int u = edges[edge_id].from;
        int v = edges[edge_id].to;
        if (in_cycle_scc[u] && in_cycle_scc[v]) {
            active[edge_id] = true;
            out_degree[u]++;
        }
    }

    queue<int> q;
    for (int u : cycle_scc) {
        if (out_degree[u] == 1) q.push(u);
    }

    vector<int> next_vertex(n + 1, 0);
    int fixed_edges = 0;

    while (!q.empty()) {
        int u = q.front();
        q.pop();

        if (next_vertex[u] != 0 || out_degree[u] != 1) continue;

        int kept_edge = -1;
        for (int edge_id : out_edges[u]) {
            if (active[edge_id]) {
                kept_edge = edge_id;
                break;
            }
        }
        if (kept_edge == -1) continue;

        int v = edges[kept_edge].to;
        next_vertex[u] = v;
        fixed_edges++;

        // u -> v is a cycle edge. Remove every other active edge entering v.
        for (int edge_id : in_edges[v]) {
            if (!active[edge_id] || edge_id == kept_edge) continue;

            active[edge_id] = false;
            int from = edges[edge_id].from;
            out_degree[from]--;
            if (out_degree[from] == 1) {
                q.push(from);
            }
        }
    }

    if (fixed_edges != (int)cycle_scc.size()) return;

    int start = cycle_scc[0];
    int current = start;
    for (int i = 0; i < (int)cycle_scc.size(); i++) {
        if (i > 0) cout << ' ';
        cout << current;
        current = next_vertex[current];
    }
    cout << '\n';
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int op;
    cin >> op;
    if (op == 1) {
        step1();
    } else {
        step2();
    }

    return 0;
}
```

## 문제 G

$d = 0$ 타입 물뿌리개의 추가는, $x$ 이하 위치에 $(x, 0)$을 통과하는 기울기 -1의 직선을 추가하는 것이고, $d = 1$ 타입 물뿌리개의 추가는, $x$ 이상 위치에 $(x, 0)$을 통과하는 기울기 1의 직선을 추가하는 것이다. 그리고 답은, 모든 직선의 min을 한 함수에서, $[l, r]$ 구간의 함숫값의 최댓값이다.

중요한 점은 유효한 교점은 많아야 $O(\log N)$개라는 것이다. 기울기 1의 직선이 기울기 -1의 직선과 교차했다면, x절편과의 거리가 적어도 두 배 이상 떨어진 점만 유효한 교점이 될 수 있다. 즉, 새로운 직선이 들어왔을 때, 그 직선으로 업데이트해야 하는 구간은 많아야 $O(\log N)$개다.

따라서, 구간에
1. 높이 최댓값 (답을 구하기 위해 필요)
2. +1 기울기 직선의 x절편 최솟값과 최댓값 (기울기 -1 직선으로 최솟값을 덮어씌울 수 있는지 판단하기 위해 필요)
3. -1 기울기 직선의 x절편 최솟값과 최댓값 (기울기 +1 직선으로 최솟값을 덮어�씌울 수 있는지 판단하기 위해 필요)
를 저장하면, 세그먼트 트리로 $O(\log^2 N)$에 직선을 추가하고, $O(\log N)$에 구간 최댓값을 구할 수 있다. 따라서, 전체 시간복잡도는 $O(Q \log^2 N)$이다.

***참고: 코드는 AI로 생성되었음.***

```cpp
#include <bits/stdc++.h>
using namespace std;

namespace {

constexpr int INF = 1'000'000'000;
constexpr int NO_LAZY = 2;

struct SegmentTree {
    struct Node {
        int max_value = 0;
        int min_minus = 0;
        int max_minus = 0;
        int min_plus = 0;
        int max_plus = 0;
        int lazy_slope = NO_LAZY;
        int lazy_intercept = 0;
    };

    int size;
    vector<Node> tree;

    explicit SegmentTree(int n) : size(n), tree(4 * n + 5) {
        apply(1, 1, size, 0, INF);
    }

    void apply(int node, int left, int right, int slope, int intercept) {
        const int left_value = slope * left + intercept;
        const int right_value = slope * right + intercept;

        tree[node].max_value = max(left_value, right_value);
        tree[node].min_minus = min(left_value - left, right_value - right);
        tree[node].max_minus = max(left_value - left, right_value - right);
        tree[node].min_plus = min(left_value + left, right_value + right);
        tree[node].max_plus = max(left_value + left, right_value + right);
        tree[node].lazy_slope = slope;
        tree[node].lazy_intercept = intercept;
    }

    void push(int node, int left, int right) {
        if (left == right || tree[node].lazy_slope == NO_LAZY) return;

        const int middle = (left + right) / 2;
        apply(node * 2, left, middle,
              tree[node].lazy_slope, tree[node].lazy_intercept);
        apply(node * 2 + 1, middle + 1, right,
              tree[node].lazy_slope, tree[node].lazy_intercept);
        tree[node].lazy_slope = NO_LAZY;
    }

    void pull(int node) {
        const Node &lhs = tree[node * 2];
        const Node &rhs = tree[node * 2 + 1];

        tree[node].max_value = max(lhs.max_value, rhs.max_value);
        tree[node].min_minus = min(lhs.min_minus, rhs.min_minus);
        tree[node].max_minus = max(lhs.max_minus, rhs.max_minus);
        tree[node].min_plus = min(lhs.min_plus, rhs.min_plus);
        tree[node].max_plus = max(lhs.max_plus, rhs.max_plus);
    }

    // A left-facing machine at x changes a[i] to min(a[i], x - i)
    // for every i <= x.
    void add_left(int x) {
        add_left(1, 1, size, 1, x, x);
    }

    void add_left(int node, int left, int right,
                  int query_left, int query_right, int x) {
        if (query_right < left || right < query_left ||
            tree[node].max_plus <= x) {
            return;
        }

        if (query_left <= left && right <= query_right &&
            tree[node].min_plus >= x) {
            apply(node, left, right, -1, x);
            return;
        }

        push(node, left, right);
        const int middle = (left + right) / 2;
        add_left(node * 2, left, middle, query_left, query_right, x);
        add_left(node * 2 + 1, middle + 1, right,
                 query_left, query_right, x);
        pull(node);
    }

    // A right-facing machine at x changes a[i] to min(a[i], i - x)
    // for every i >= x.
    void add_right(int x) {
        add_right(1, 1, size, x, size, x);
    }

    void add_right(int node, int left, int right,
                   int query_left, int query_right, int x) {
        if (query_right < left || right < query_left ||
            tree[node].max_minus <= -x) {
            return;
        }

        if (query_left <= left && right <= query_right &&
            tree[node].min_minus >= -x) {
            apply(node, left, right, 1, -x);
            return;
        }

        push(node, left, right);
        const int middle = (left + right) / 2;
        add_right(node * 2, left, middle, query_left, query_right, x);
        add_right(node * 2 + 1, middle + 1, right,
                  query_left, query_right, x);
        pull(node);
    }

    int range_max(int query_left, int query_right) {
        return range_max(1, 1, size, query_left, query_right);
    }

    int range_max(int node, int left, int right,
                  int query_left, int query_right) {
        if (query_right < left || right < query_left) return -INF;
        if (query_left <= left && right <= query_right) {
            return tree[node].max_value;
        }

        push(node, left, right);
        const int middle = (left + right) / 2;
        return max(range_max(node * 2, left, middle,
                             query_left, query_right),
                   range_max(node * 2 + 1, middle + 1, right,
                             query_left, query_right));
    }
};

}  // namespace

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;

    SegmentTree segment_tree(n);

    while (q--) {
        int type;
        cin >> type;

        if (type == 1) {
            int direction, x;
            cin >> direction >> x;

            if (direction == 0) {
                segment_tree.add_left(x);
            } else {
                segment_tree.add_right(x);
            }
        } else {
            int left, right;
            cin >> left >> right;

            const int answer = segment_tree.range_max(left, right);
            cout << (answer >= INF / 2 ? -1 : answer) << '\n';
        }
    }

    return 0;
}
```

## 문제 A

이분 매칭은 Matroid 성질 때문에, 독립 집합의 교환 성질(Augmentation/Exchange Property)을 사용할 수 있다. 따라서, $r$번 정점을 추가할 때, 정점이 부족하다면 제거할 수 있는 가장 작은 번호의 정점을 제거하는 것만으로 모든 $l$에 대해 $[l, r]$ 구간에서의 최대 매칭을 유지할 수 있다. 따라서 시간복잡도는 $O(N^2)$이다.
